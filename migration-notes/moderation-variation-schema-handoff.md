# Moderation variation schema handoff

The local Rust schema feature is implemented and validated against the pinned Mongoose/BSON source oracle. Model descriptors, defaults, casts, indexes, schema boundary and raw Mongo repository behavior are in [`moderation_variation.schema.rs`](../dimabot/src/schemas/moderation_variation.schema.rs); `moderation-variation-storage` gates the feature. Constructors do not connect or install indexes. Callers choose a database explicitly and may install declared indexes through the repository.

The accepted schema oracle used Node 24.22.1, TypeScript 5.9.3, Mongoose 8.24.2 and BSON 6.10.4. Its 42 model/input cases and full BSON hex bytes matched Rust replay; isolated private MongoDB exercised CRUD and index installation. See the [schema evidence](evidence/2026-10-30-variation-schema/README.md), [verification summary](evidence/2026-10-30-variation-schema/verification-summary.json) and [source bindings](evidence/2026-10-30-variation-schema/source-bindings.json). That schema epoch and its prior attempts remain preserved independently.

## Verified `VariationJob.providerUsage` declared type

The source interface declares `providerUsage: Array<Record<string, unknown>>`. The native `VariationJob` now represents it as `Vec<Document>` with owned conversion paths that move usage documents; the borrowed conversion remains available. This changes the Rust API for callers constructing or reading this field. The source-bound epoch adds six cases for document-array values and type boundaries while retaining all 42 prior constructor cases, collection names, indexes and BSON wires unchanged. The 1,507 source inputs bind to commit `60e0fe66e2399f435cf194bd880c3965e82d39b3`, with 1,497 Git files and ten reused SDK inputs; all were independently verified. See the [dated type-closure note](moderation-variation-job-type-2026-10-30.md) and its [separate evidence package](evidence/2026-10-30-variation-job-type/README.md).

Formatting, Node/oracle validation, all five native schema tests, the 42-case replay, six new usage-shape constructor cases, isolated Mongo CRUD/index checks, scoped Clippy, minimal profile and all-feature strict checks passed. An earlier compiler wrapper omitted required private Mongo fixture variables and stopped before that database test; source was unchanged, the wrapper was corrected, and the full suite passed. This harness failure is retained separately from the successful run.

## Contract boundary and remaining work

Raw BSON repositories preserve Mongoose-compatible missing, null and Mixed shapes. `VariationCache` and `VariationJob` are strict typed views for complete application values and reject incomplete or incompatible raw documents; use raw BSON when those shapes must round-trip. The new type evidence does not change that boundary. Arbitrary JavaScript prototypes, hooks/getters, `undefined`, sparse arrays or full serialized-value parity are not claimed.

The TypeScript schema remains live. Targeted source comparison of caller-shaped filters and updates—including failed-state claims, provider-usage `$push` and cache upserts—remains before schema retirement. Caller adoption is separate, and the surrounding variation-jobs service remains a distinct feature. No deployment, push, performance benchmark or RSS/allocation claim follows. Production readback found 18 containers unchanged and zero task-owned resources.
