Open **Modules → AI Personality** in your channel dashboard to configure how DomDimaBot responds in chat. The module has a master switch. Stream summaries and clip recommendations have separate switches on the same page.

## Profiles and tone

Each profile has a name, personality prompt, persona mode, tone preset, optional persona reference, voice style fields, and catchphrases. Select the active profile before editing it. You can also add rules that guide responses.

| Plan | Profiles | Rules | Known users | Chat context window |
|---|---:|---:|---:|---:|
| Free | 1 | 3 | 3 | 7 |
| Premium | 2 | 5 | 10 | 15 |
| Pro | 3 | Unlimited | Unlimited | 35 |

The context window is the configured number of recent chat messages considered by the personality feature. It does not guarantee that every message will produce a response.

## Known users

Add a Twitch username, a short description, and an optional relationship for community members you want the bot to recognize. The bot can use this information when responding. Avoid storing private or sensitive information in these fields.

## Learning and memory

The page includes learning controls for memory suggestions and confirmation, post-stream summaries, maintenance, and automatic application of suggested changes. Review the automatic create, edit, archive, and delete switches before enabling them. The memory policy also lets you choose whether to prioritize recent chat and which kinds of remembered information can be used.

AI replies can vary. Test a profile in your channel, then adjust its prompt and rules if its responses do not fit your community. For chat filtering and temporary link permits, see [Chat Moderation](/moderation/).
