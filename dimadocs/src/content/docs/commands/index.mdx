## Where to manage commands

- **In chat:** `!commands` lists the commands you can use in this channel. Moderators can create, edit, and delete custom commands with `!cc`, `!ec`, and `!dc`.
- **On the dashboard:** open **Commands** to turn commands on or off, change who can use them, set cooldowns, and edit replies.
- **For viewers:** the **Viewer list** on the Commands page lists the commands each viewer can use. Use **Copy link** to share it.
