Text to speech (TTS) reads messages aloud on your stream. Your viewers use the `!s` chat command, and your commands and channel point rewards can use AST functions. The audio plays through a browser source in OBS, so the stream hears it.

**Who can change it:** the channel owner, or an admin with `tts:manage`. Admins with `tts:view` can see the settings but cannot change them.

**Plans:** every plan includes every voice engine. Usage comes from your monthly [AI credits](#ai-credits-and-fallbacks).

## Set up the speech overlay

1. Go to **Modules → Text to Speech** and turn on **Enable channel TTS**.
2. In **Speech URL**, click **Copy URL**.
3. In OBS, add a **Browser Source** with that URL. Keep the source active while you want speech to play.
4. Check that the **Speech Chat** command (`!s`) is on under **Commands**. Then type `!s Hello chat!` in your chat to test it.

If the browser source is not connected, new speech requests are refused with the message "Speech overlay is not connected." Queued speech waits until the source reconnects.

## Choose a voice engine

Pick the engine in **Modules → Text to Speech → Voice**. The engine you pick is the default for `!s` and for `$(tts ...)`.

| Engine | Voices | Cost | Voice tags |
|---|---|---|---|
| **Piper** | One English voice (Ryan, `en_US-ryan-medium`) and one Spanish voice (Ald, `es_MX-ald-medium`). | 1 credit per 50 characters, rounded up. | Removed. |
| **Kokoro** | Preset voices, for example `af_heart` (English) and `ef_dora` (Spanish). | 1 credit per 15 characters, rounded up. | Removed. |
| **Fish Audio** | Cloned voices. Four built-in voices, plus any voice you find in the voice browser. | 1.5 credits per character, rounded up. | Works. |

**Dima Voice** appears in the list as "Coming soon." You cannot select it yet.

### Piper

Piper uses the Ryan voice for English and the Ald voice for Spanish. The dashboard uses the channel's default language to choose between them.

Piper keeps working when your credits run out. Its usage can make your credit balance negative.

### Kokoro

Use Kokoro for a set of preset voices. Pick a default Kokoro voice in the dashboard, or choose one per command with `$(tts.kokoro voice_name text)`.

### Fish Audio

Fish Audio provides cloned voices. The four built-in voices are:

- `gojo` (Gojo)
- `rias_gremory` (Rias Gremory)
- `toji_fushiguro` (Toji Fushiguro)
- `carlos_bodoque` (Carlos Bodoque)

Fish Audio is the only engine that reads [voice tags](#voice-tags-fish-audio-only).

### Find and save Fish voices

Open **Find voice** in the Fish Audio section to search the voice library. Samples from Fish play for free. Generating a preview uses credits.

Click the star on a voice to save it as a **favorite**. A channel can keep up to 20 favorites. Then give a favorite a **nickname** so you can use it in commands:

- Use 1–40 letters, numbers, or underscores. Start with a letter.
- Nicknames are not case sensitive. They are saved in lowercase.
- Nicknames must be unique. You cannot use the names of the four built-in voices.
- If you do not set a nickname, DomDimaBot creates one from the voice name. For example, **Pinky Pie** becomes `pinky_pie`. If that name is taken, a number is added, such as `pinky_pie_2`.

Only owners and admins with `tts:manage` can save, rename, or remove favorites.

### Use a Fish voice in a command

For `$(tts.clone ...)` and its alias `$(tts.fish ...)`, the first argument is one voice key. Use a built-in key, a favorite's nickname, or a Fish voice ID. Names with spaces do not work here.

```text
$(tts.fish carlos_bodoque &t)
$(tts.fish bodoquin &t)
```

In the first line, `&t` is the text the viewer typed. In the second line, `bodoquin` is the nickname of a saved favorite.

`$(set.voice ...)` also accepts a favorite's full display name, including spaces.

## Chat command: `!s`

**Usage:** `!s <message>`

`!s` runs as a normal AST command. It reads the message with the channel's default engine and voice. The shipped **Speech Chat** command is on for everyone, with no cooldown.

The default template is:

```text
$(tts $(user) dice: &t)
```

So chat hears the viewer's name, then `dice:`, then the message. To change the wording, edit the **Speech Chat** command under **Commands** or from the TTS page. The language setting changes the voice, not the template text.

```text
!s Hello chat, welcome to the stream!
```

Chat messages go through the [message filters](#message-filters-and-limits) before they are read. If nothing readable is left after filtering, the request is refused.

**Cooldowns:** the Speech Chat command has a 0-second cooldown. Each channel can have only one editable command with a 0-second cooldown. Other commands must wait at least 5 seconds on Free, 3 seconds on Premium, or 1 second on Pro.

## AST functions

Use these in custom commands, timers, and channel point rewards. See [Advanced commands](/commands/advanced/) for how AST works.

| Function | What it does |
|---|---|
| `$(tts <message>)` | Speaks with the channel's default engine and voice. |
| `$(tts.ai <message>)` | Same as `$(tts ...)`. |
| `$(tts.speak <message>)` | Speaks with Piper, even when another engine is the default. |
| `$(tts.piper <message>)` | Same as `$(tts.speak ...)`. |
| `$(tts.kokoro <voice> <message>)` | Speaks with a Kokoro preset voice, such as `ef_dora`. |
| `$(tts.clone <voice> <message>)` | Speaks with a Fish Audio voice. The first argument is a built-in key, a favorite's nickname, or a Fish voice ID. |
| `$(tts.fish <voice> <message>)` | Same as `$(tts.clone ...)`. |
| `$(set.voice <voice>)` | Changes the channel's default Fish voice and makes Fish the default engine. Accepts a built-in key, a favorite's nickname, or a favorite's display name. The bot then posts "TTS voice changed to …" in chat. Requires moderator level. |

```text
$(tts Hello chat!)
$(tts.speak This uses Piper.)
$(tts.kokoro ef_dora Hola chat!)
$(tts.clone gojo Hello from Gojo!)
$(tts.fish carlos_bodoque &t)
$(set.voice my_favorite)
```

Functions that read viewer text, such as `&t`, work best in channel point rewards that have **Viewer must type something** turned on. See [Channel Rewards](/rewards/).

### Queue and overlay behavior

- Speech plays in order, one item at a time, for each channel.
- The **Maximum messages waiting** setting counts the message that is playing now. With the default of 5, one message can play and four can wait.
- If the browser source is disconnected, new requests are refused. Messages already waiting stay in the queue and play when the source reconnects.
- A message that was interrupted by a disconnect is not replayed.

## Message filters and limits

Set these in **Modules → Text to Speech → Message limits**:

| Setting | Default | Range | What it does |
|---|---|---|---|
| **Maximum characters per message** | 280 | 30–500 | Longer messages are cut to this length. |
| **Maximum messages waiting** | 5 | 1–20 | The queue size, including the message that is playing. |
| **Skip emotes** | On | | Removes emote names before reading. |
| **Links become [link]** | On | | Removes links. Nothing is read in their place. |
| **Tidy extra spaces** | On | | Collapses repeated spaces. |

The filters apply to chat messages and to AST speech. Filters run before the length limit, so a cut-off message never reads half a tag.

## Voice tags (Fish Audio only)

Fish Audio can change how a line sounds when you add a tag in square brackets:

```text
!s [happy] Great stream today!
!s [whisper] [pause] Can you keep a secret?
$(tts.clone gojo [excited] Let's go!)
```

Owners and admins with `tts:manage` can turn tags on or off in **Modules → Text to Speech → Voice tags**. All tags are on by default. A tag that is off, or that the bot does not recognize, is removed before synthesis. Piper and Kokoro remove every tag and read the rest of the message.

The tags are:

### Emotions

`[happy]` `[sad]` `[angry]` `[excited]` `[calm]` `[nervous]` `[confident]` `[surprised]` `[scared]` `[worried]` `[disappointed]` `[curious]` `[sarcastic]` `[satisfied]` `[delighted]` `[upset]` `[frustrated]` `[depressed]` `[empathetic]` `[embarrassed]` `[disgusted]` `[moved]` `[proud]` `[relaxed]` `[grateful]` `[disdainful]` `[unhappy]` `[anxious]` `[hysterical]` `[indifferent]` `[uncertain]` `[doubtful]` `[confused]` `[regretful]` `[guilty]` `[ashamed]` `[jealous]` `[envious]` `[hopeful]` `[optimistic]` `[pessimistic]` `[nostalgic]` `[lonely]` `[bored]` `[contemptuous]` `[sympathetic]` `[compassionate]` `[determined]` `[resigned]`

### Voice and delivery

`[whisper]` `[shouting]` `[soft]` `[singing]` `[slow]` `[fast]` `[emphasis]` `[screaming]`

### Vocal sounds

`[laugh]` `[chuckle]` `[giggle]` `[cry]` `[sigh]` `[gasp]` `[inhale]` `[exhale]` `[sobbing]` `[groaning]` `[panting]` `[yawning]` `[snoring]` `[clear throat]`

### Pauses and effects

`[pause]` `[long-pause]` `[audience laughing]` `[background laughter]`

Some short forms also work. For example, `[anger]` means `[angry]`, `[whispering]` means `[whisper]`, `[laughing]` means `[laugh]`, and `[crowd laughing]` means `[audience laughing]`. Turning off a tag also turns off its short forms.

## Channel admin access

Channel owners always have access to TTS. For channel admins, the permissions are separate:

- `tts:view` lets an admin read the TTS settings.
- `tts:manage` lets an admin change the settings, save or rename favorites, and preview voices. It includes `tts:view`.
- `commands:manage` lets an admin edit the **Speech Chat** `!s` command. It does not give access to the TTS settings.
- `*` gives full access to TTS and commands.

You can combine these with `chat:admin`. For example, an admin can manage chat but only view the TTS settings.

## AI credits and fallbacks

AI credits are shared by all AI features on your channel. Each plan includes this many credits per month:

| Plan | Monthly AI credits |
|---|---:|
| Free | 25,000 |
| Premium | 200,000 |
| Pro | 800,000 |

Credits per message:

- **Piper:** 1 credit per 50 characters, rounded up.
- **Kokoro:** 1 credit per 15 characters, rounded up.
- **Fish Audio:** 1.5 credits per character, rounded up for each message.
- **Voice previews** use credits the same way as the engine they preview.

If credits run out or a voice cannot be generated, TTS switches to a fallback voice so speech keeps working:

- **Credits run out, Fish Audio requested:** Free plans switch to Piper. Premium and Pro plans switch to Kokoro.
- **Fish Audio or Kokoro fails to generate audio:** the message is read with Piper.
- **Credit status cannot be checked:** the message is read with Piper.

The voice you chose stays saved. Only the message that needed the fallback uses the fallback voice.

For your channel's settings in general, see the [dashboard](/dashboard/) guide.
