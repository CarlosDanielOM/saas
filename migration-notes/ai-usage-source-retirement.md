## Coverage and limits

The retired helper's pure behavior has a native mapping in `src/utils/ai_usage.rs` and `src/utils/ai_usage_lossless.rs`. The Node resolver and Rust source-sensitive paths resolve the archived TypeScript source under its logical source identity and verify its pinned bytes. The accepted corpus covers 130 context and two metadata cases. The bounded mapping includes declared typed inputs, ordinary own-property JSON, UTF-16 strings, ECMAScript trimming, JSON coercion/order and UUID v4 behavior. Accessors, symbols, custom prototypes and executable JavaScript objects are outside the lossless JSON contract.

The parent migration matrix rollup is 18 complete and 23 partial features. This helper contributes one completed local feature; its source test is validation evidence, not a separate feature. This retirement does not migrate application callers. `polarsh.ts` and `posthog_events.ts` still use runtime helper behavior; ledger, receipts, TTS and ledger tests retain type or test references. Those surrounding TypeScript paths remain active, so total AI usage migration is incomplete. Runtime adoption, deployment and production cutover were not part of this work.
