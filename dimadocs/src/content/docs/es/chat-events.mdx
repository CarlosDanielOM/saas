Eventos del chat hace que el bot publique un mensaje en tu chat cuando pasa algo en tu canal, como un follow, un raid o un cheer de Bits. Cada evento es una tarjeta que puedes activar, desactivar y personalizar. El bot recibe estos eventos de Twitch mediante EventSub, el sistema de notificaciones de eventos de Twitch. No necesitas configurar EventSub tú mismo.

**Quién puede cambiar los eventos:** el propietario del canal o un administrador con el permiso de **Gestión de eventos**. Los demás administradores solo pueden ver la página.

**Planes:** algunos eventos requieren Premium o Pro. Las tarjetas bloqueadas muestran el botón **Mejorar plan**.

## Configurar un evento

1. Abre **Módulos → Eventos del chat**. La página muestra cuántos eventos están activos (por ejemplo, "2 de 9 activos") y los agrupa en **Momentos de la comunidad** y **Tu stream**.
2. Abre una tarjeta y completa los campos de **Configuración**. Los campos cambian según el evento; la tabla **Qué puede hacer cada evento** más abajo los detalla.
3. Pulsa **Guardar Cambios**.
4. Activa el evento con su interruptor. Si el canal todavía no tiene una suscripción para ese evento, el panel la crea en Twitch.

Para quitar un evento, abre su configuración y pulsa **Eliminar Evento**.

## Desactivar, eliminar o silenciar

- **Desactivado** (el interruptor) conserva la suscripción de Twitch. Puedes volver a activarla cuando quieras.
- **Eliminar Evento** borra la suscripción. Más adelante puedes volver a agregar el evento.
- **Inicio de stream** y **Fin de stream** no se pueden desactivar ni eliminar. Para silenciarlos, borra su mensaje.

Deja un mensaje vacío si no quieres que el bot diga nada en ese evento.

## Qué puede hacer cada evento

Escribe estas variables en el mensaje de un evento. Cuando ocurre el evento, el bot las reemplaza por el valor real.

| Evento | Variables | Opciones adicionales |
|--------|-----------|----------------------|
| Follow | `$(user)` | |
| Inicio de stream | `$(twitch.channel)`, `$(twitch.game)` | |
| Fin de stream | `$(twitch.channel)` | |
| Raid | `$(raid.channel)`, `$(raid.login)`, `$(raid.viewers)` | Mínimo de espectadores. Los raids por debajo se omiten. Casilla para clips. |
| Pausa publicitaria | `$(ad.time)` (segundos) | Mensaje final con su propia casilla para activarlo o desactivarlo |
| Suscripción | `$(user)`, `$(sub.tier)` | |
| Suscripción regalada | `$(user)`, `$(sub.tier)`, `$(gifted.user)` | |
| Resuscripción | `$(user)`, `$(sub.tier)`, `$(sub.months)` | |
| Bits (cheer) | `$(user)`, `$(cheer.amount)`, `$(cheer.message)` | Niveles de mensaje: **Bits mínimos**, **Bits máximos**, **Mensaje** |
| Hype Train | `$(hypetrain.level)`, `$(hypetrain.progress)`, `$(hypetrain.end)` | |
| Shoutout recibido | `$(shoutout.channel)`, `$(twitch.channel)` | |
| Notificaciones del chat | `$(user)`, `$(twitch.streak)`, `$(twitch.modiversary)` | Rachas de visualización y aniversarios de moderación, cada uno con su casilla y su mensaje |

Usa el marcador que muestra cada control. Si un control no indica una variable, no asumas que el evento la admite.

## Niveles de Bits y límites por plan

Cada tarjeta muestra el plan que requiere. El servidor revisa el plan cada vez que creas o cambias una suscripción.

Los niveles de mensaje de Bits tienen un límite por plan. Si el evento no define su propio límite, el servidor usa **0** niveles en Free, **2** en Premium y **5** en Pro. El editor no te impide agregar niveles cuando el evento no tiene límite, así que puedes llenar más de los que permite tu plan. Entonces el guardado se rechaza con un mensaje como "Tu plan premium permite hasta 2 niveles de Bits".

## Eventos que escucha el bot

De forma predeterminada, el bot se suscribe a estos eventos de Twitch: mensajes del chat, follows, inicio y fin de stream, raids, Hype Train, shoutouts recibidos, pausas publicitarias, suscripciones, suscripciones regaladas, resuscripciones, Bits, avances de encuestas y predicciones, actualizaciones del canal y del usuario, y mensajes retenidos por AutoMod.

Los Bits usan el evento actual `channel.bits.use`. Las suscripciones antiguas `channel.cheer` y `channel.bit.use` aparecen en la misma tarjeta de Bits.

No todas las suscripciones tienen tarjeta. Las tarjetas vienen del catálogo del bot, así que una suscripción sin tarjeta no aparece en esta página.

## Solución de problemas

- **Falta un evento:** el catálogo del bot no lo incluye. Una suscripción de Twitch por sí sola no crea una tarjeta.
- **Falla la activación:** comprueba que tu cuenta tenga el permiso de Gestión de eventos, que tu plan incluya el evento (el mensaje indica el plan necesario) y que la autorización de Twitch esté vigente.
- **El evento está activado, pero no aparece nada en el chat:** comprueba que el mensaje no esté vacío y que su configuración sea correcta. Un raid por debajo del mínimo de espectadores se omite a propósito.
