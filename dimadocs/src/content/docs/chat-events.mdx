title: Chat Events
description: Choose which Twitch events (follows, subs, raids, Bits, ad breaks) the bot announces in your chat, and edit each message.

Chat Events makes the bot post a message in your chat when something happens on your channel, such as a follow, a raid, or a Bits cheer. Each event is a card you can turn on, turn off, and customize. The bot gets these events from Twitch through EventSub, Twitch's event notification system. You don't need to set EventSub up yourself.

**Who can change events:** the channel owner, or an admin with the events **Manage** permission. Other admins can only view the page.

**Plans:** some events need Premium or Pro. Locked cards show an **Upgrade** button.

## Set up an event

1. Open **Modules → Chat Events**. The page shows how many events are on (for example, "2 of 9 on") and groups them into **Community moments** and **Your stream**.
2. Open a card and fill in its **Configuration** fields. The fields depend on the event; the **What each event can do** table below lists them.
3. Select **Save Changes**.
4. Turn the event on with its toggle. If the channel has no subscription for that event yet, the dashboard creates one with Twitch.

To remove an event, open its configuration and select **Delete Event**.

## Turn off, delete, or silence

- **Off** (the toggle) keeps the Twitch subscription. Turn it on again any time.
- **Delete Event** removes the subscription. You can add the event back later.
- **Stream online** and **Stream offline** can't be turned off or deleted. To silence them, clear their message.

Leave a message empty if you don't want the bot to say anything for that event.

## What each event can do

Put these variables in an event's message. The bot replaces each one with the real value when the event happens.

| Event | Variables | Extra settings |
|-------|-----------|----------------|
| Follow | `$(user)` | |
| Stream online | `$(twitch.channel)`, `$(twitch.game)` | |
| Stream offline | `$(twitch.channel)` | |
| Raid | `$(raid.channel)`, `$(raid.login)`, `$(raid.viewers)` | Minimum viewers. Raids below it are skipped. Clip switch. |
| Ad break | `$(ad.time)` (seconds) | Ending message with its own on/off switch |
| Subscription | `$(user)`, `$(sub.tier)` | |
| Gifted subscription | `$(user)`, `$(sub.tier)`, `$(gifted.user)` | |
| Resubscription | `$(user)`, `$(sub.tier)`, `$(sub.months)` | |
| Bits (cheer) | `$(user)`, `$(cheer.amount)`, `$(cheer.message)` | Message tiers: **Min Bits**, **Max Bits**, **Message** |
| Hype Train | `$(hypetrain.level)`, `$(hypetrain.progress)`, `$(hypetrain.end)` | |
| Shoutout received | `$(shoutout.channel)`, `$(twitch.channel)` | |
| Chat Notifications | `$(user)`, `$(twitch.streak)`, `$(twitch.modiversary)` | Watch streaks and moderator anniversaries, each with its own switch and message |

Use the placeholder shown by each control. If a control doesn't list a variable, don't assume the event supports it.

## Bits tiers and plan limits

Each card shows its plan requirement. The server checks the plan every time you create or change a subscription.

Bits message tiers have a limit per plan. If the event doesn't set its own limit, the server uses **0** tiers on Free, **2** on Premium, and **5** on Pro. The editor doesn't stop you from adding tiers when the event has no limit, so you can fill in more than your plan allows. The save is then rejected with a message such as "Your premium plan allows up to 2 cheer tiers."

## Events the bot listens for

By default, the bot subscribes to these Twitch events: chat messages, follows, stream online and offline, raids, Hype Train, received shoutouts, ad breaks, subscriptions, gifted subscriptions, resubscriptions, Bits, poll and prediction progress, channel and user updates, and AutoMod held messages.

Bits use the current `channel.bits.use` event. Older `channel.cheer` and `channel.bit.use` subscriptions appear on the same Bits card.

Not every subscription has a card. The cards come from the bot's catalog, so a subscription without a card doesn't appear on this page.

## Troubleshooting

- **An event is missing:** the bot's catalog doesn't include it. A Twitch subscription alone doesn't create a card.
- **Enabling fails:** check that your account has the events Manage permission, that your plan includes the event (the message names the plan it needs), and that Twitch authorization is current.
- **The event is on but nothing appears in chat:** check that the message isn't empty and that its settings are right. A raid below the minimum viewers is skipped on purpose.
