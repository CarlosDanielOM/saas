# Links moderation verification handoff (2026-10-29)

**Status: verified selected typed evaluator; no caller adoption or deployment.** The native implementation covers the sole runtime export `evaluateLinksRule`, its result type, and the selected type-only schema contract `Pick<IModerationRule, 'allowlistDomains'>` (`string[]`). Nullish fallbacks for `text` and `allowlistDomains` are represented explicitly. This closes only the `links.rule.ts` source row; the surrounding registry, handler, settings persistence and enforcement remain TypeScript.

The source regex is deliberately permissive, not a URL validator. The native UTF-16 scanner preserves its actual global `/gi` matching behavior, including greedy dotted-host continuation, protocol/www prefixes, paths, permissive host extraction, duplicate hosts, and first blocked host. It precomputes run endpoints and continuation candidates, lowercases each entire URL match before splitting the host, and lowercases allowlist domains without trimming. The port reuses `JsString`, `js_compat` and the verified Unicode 17 lowercase core. No additional runtime or service adapter is needed for this typed evaluator.

Pinned actual-source checks passed 45,057 cases. The full contract, implementation, test/build receipts, and remaining migration limits are recorded in [moderation-text-2026-10-29.md](moderation-text-2026-10-29.md) and the indexed [evidence package](evidence/2026-10-29-moderation-text/README.md). The source and callers remain live and unchanged; no deployment, source retirement, or push occurred. No benchmark or performance improvement is claimed.
