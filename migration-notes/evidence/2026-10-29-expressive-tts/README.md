## Benchmark artifacts and limits

All nine prepared workloads use seven samples and 100 warmups. Iterations are 10,000 except two large workloads at 1,000. Inputs were prepared before timing; the timed region is the filter/reinforcement operation plus a checksum over every UTF-16 output unit. There is no JSON serialization, file I/O, fixture preparation, or provider/network call in the timed operation. Input SHA-256 `95bbc229a92de5f1b8d12c36e69ab2af3ed06cee160ec31dfe1d24c812a6b195` remained constant across baseline and optimized runs, and exact UTF-16 outputs and checksums were verified before/during timing.

- Baseline input and Node/Rust reports: [`initial-benchmark/expressive-benchmark-inputs.json`](initial-benchmark/expressive-benchmark-inputs.json), [`initial-benchmark/expressive-node-benchmark.json`](initial-benchmark/expressive-node-benchmark.json), and [`initial-benchmark/expressive-rust-benchmark.json`](initial-benchmark/expressive-rust-benchmark.json); baseline comparison: [`initial-benchmark/comparison.json`](initial-benchmark/comparison.json).
- Final input and Node/Rust reports: [`final-benchmark/expressive-benchmark-inputs.json`](final-benchmark/expressive-benchmark-inputs.json), [`final-benchmark/expressive-node-benchmark.json`](final-benchmark/expressive-node-benchmark.json), and [`final-benchmark/expressive-rust-benchmark.json`](final-benchmark/expressive-rust-benchmark.json); paired report: [`comparison.json`](comparison.json), [chart](comparison.html).
- Keep all five baseline filter regressions and all three final regressions visible. Final regressions are filter aliases, filter lone surrogate, and reinforcement lone surrogate. The large filter workload is near parity, without a significance claim.
- Node baseline and final reinforcement timings varied materially even though reinforcement code did not change. Do not attribute the changes in reinforcement ratios to the filter-only Rust optimization.
- Measurements were sequential on a shared host, not interleaved. They support no CPU, RSS, provider latency, production performance, or blanket Rust-faster claim.
