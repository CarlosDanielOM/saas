# Advanced moderation semantic policy prerequisite

**Status (2026-10-30): bounded semantic-policy subset verified against the pinned source oracle and Rust checks.** The `advanced_policy.rs` subset covers six constants, `emptySemanticPolicy`, strict `paidModeration`, semantic interface types, and the semantic section of `parseAdvancedRule`. This is not the full parser or moderation feature.

The source-ordered checks cover semantic object, enabled, threshold, policy type and normalized length/enabled requirement, uncertain option, examples array/count, and each example. The source preserves the original example message and trims policy text. `categories` and `broadcasterInvitation` are interface-only in this parser: input values are ignored and output properties absent. The outer parser validates patterns first and applies the blacklist-only restriction after semantic normalization; neither behavior is implemented here.

Verification used the isolated Node 24 fixture and final pinned source snapshot. The semantic source replay covered 81 selected cases, plus 14 paid-tier cases and six constants. Three nonfinite-number cases were excluded from the 84 selected cases because JSON transport cannot represent those source-only values; this limitation is retained explicitly. Rust policy checks passed four ordinary tests and the external source replay. The final capped compiler phase passed scoped strict Clippy, the all-target no-default and Mongo+Redis checks, and all-feature/all-target strict Clippy. A prior helper replay phase successfully ran its codec and Unicode replay checks, then failed later on `useless_vec` in a policy test; the one-line test fix changed no helper input bytes. Full receipt history is in the [evidence package](evidence/2026-10-30-advanced-moderation-prerequisites/).

`JsonView` preserves ordinary JSON distinctions and `JsString` preserves UTF-16 text and JavaScript trimming/length. `None` means missing/undefined; JSON null is present and rejected for these fields. Nonfinite JSON exponents are rejected. Arbitrary JS objects, prototypes, accessors, non-JSON NaN/Infinity values, symbols, and functions are outside this subset.

## Remaining dependencies

Regex validation/execution, pattern identifiers/cache, full outer parsing, and `matches` are still blocking dependencies. The advanced feature therefore remains incomplete; do not count this semantic subset as full local feature coverage or total migration completion. No deployment, caller adoption, TypeScript retirement, release build, or benchmark is implied. The experimental `re2_native` draft was unverified at the prerequisite freeze and is excluded. See [advanced moderation prerequisites](moderation-advanced-prerequisites.md) for combined limits and migration status.
