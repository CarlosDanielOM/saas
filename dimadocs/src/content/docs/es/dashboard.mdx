El panel de control de DomDimaBot es tu centro para configurar y monitorear tu bot.

## Secciones del Panel

### Vista General

La vista principal del panel muestra:
- Estado actual de la transmisión
- Estadísticas rápidas (espectadores, seguidores, comandos usados)
- Feed de actividad reciente
- Disparadores activos

### Comandos

- Crear y editar comandos de chat
- Configurar permisos y enfriamientos
- Previsualizar respuestas de comandos
- Organizar comandos con etiquetas

### Recompensas

- Gestionar recompensas de puntos del canal
- Ver historial de canjes
- Configurar recompensas automatizadas vs manuales
- Configurar períodos de enfriamiento

### Disparadores

- Subir archivos de medios (sonidos, imágenes)
- Configurar eventos de disparadores
- Probar secuencias de disparadores
- Monitorear estado de conexión de OBS

### Ajustes

- **General** — Nombre del canal, idioma, zona horaria
- **Permisos** — Quién puede usar qué funciones
- **Moderación** — Ajustes de auto-moderación
- **Integraciones** — Conectar servicios externos

## Acciones Rápidas

Accede a acciones comunes desde la barra de navegación superior:

| Acción | Descripción |
|--------|-------------|
| **Probar Comando** | Probar rápidamente cualquier comando |
| **Alternar Modo Transmisión** | Habilitar/deshabilitar funciones específicas de transmisión |
| **Parada de Emergencia** | Deshabilitar todos los disparadores instantáneamente |
| **Refrescar Panel** | Forzar sincronización con Twitch |

## Navegación

Usa la barra lateral para navegar entre secciones. La barra lateral es contraíble en pantallas más pequeñas.

- **Panel de Control** — Vista general y acciones rápidas
- **Comandos** — Gestionar comandos de chat
- **Recompensas** — Recompensas de puntos del canal
- **Disparadores** — Medios y automatización
- **Personalidad IA** — Ajustes de carácter del bot
- **Analíticas** — Métricas e insights de transmisión
- **Ajustes** — Opciones de configuración
