Custom commands are replies you write. When a viewer types `!discord`, the bot answers with your link. Moderators can create them in chat or on the dashboard.

For things the bot already does, such as `!so` or `!poll`, see [Built-in commands](/commands/built-in/).

## Create a command

<Tabs>
<TabItem label="In chat">

Type `!cc`, then the name (without `!`), then the reply:

```
!cc <name> <reply>
```

**Example:**
```
😎 Streamer: !cc discord Check out my Discord! discord.gg/example
🤖 DomDimaBot: Command discord created
```

**With options:**
```
!cc -cd=300 -ul=tier1 discord Subscribers-only Discord link! discord.gg/subonly
🤖 DomDimaBot: Command discord created
```

| Option | What it sets | Default |
|--------|--------------|---------|
| `-cd=` | Seconds viewers must wait between uses. Minimum: Free `5`, Premium `3`, Pro `1`. `0` is allowed for one editable command per channel. | `10` |
| `-ul=` | Who can use it. Use a number `1`–`10` or a name from the table below. | `1` (everyone) |

| Number | Name | Who |
|--------|------|-----|
| `1` | `everyone` | Anyone in chat |
| `2` | `tier1` | Subscribers |
| `3` | `tier2` | Tier 2 subs |
| `4` | `tier3` | Tier 3 subs |
| `5` | `vip` | VIPs |
| `6` | `founder` | Founders |
| `7` | `mod` | Mods and above |
| `8` | `editor` | Editors and above |
| `9` | `admin` | Admins and above |
| `10` | `broadcaster` | Only you (`streamer` also works) |

`-ul=7` and `-ul=mod` mean the same thing.

Chat replies you may see:

- `Command already exists`: the name is taken, including built-in names such as `so`.
- `Command cooldown must be 0 or at least N seconds`: the `-cd=` value is below your plan's minimum.
- `User level X is invalid`: the `-ul=` value is not in the table.

</TabItem>
<TabItem label="On the dashboard">

1. Open **Commands** in the navbar.
2. Click **New command**. Use **New keyword** for words that should trigger a reply without `!`.
3. Fill in **Name** (the word after `!`) and **Reply**.
4. Set **Wait between uses** and **Who can use it**.
5. Optional: turn on **Repeat this command on a timer** and choose the minutes.
6. Click **Create**.

</TabItem>
</Tabs>

## Edit, turn off, or delete a command

- **Edit the reply:** `!ec <name> <new reply>`.
- **Change only the cooldown or access:** `!ec -cd=<seconds> <name>` or `!ec -ul=<level> <name>`. Leave out the reply to keep it. Put options before the name.
- **Delete:** `!dc <name>`. Built-in commands can't be deleted.
- **Turn on or off:** `!enable <name>` or `!disable <name>`. The name works with or without `!`.

You can only edit or delete a command if your access level is at least the level the command requires. Commands that use tags or account rules can only be managed by moderators in chat, and `-ul=` can't be used on them. Change their rules on the dashboard.

## Cooldowns and access

- **Cooldown is shared by the whole channel.** After one viewer uses a command, nobody can use it again until the wait ends.
- **Plan minimums:** Free `5` seconds, Premium `3`, Pro `1`. The dashboard form accepts up to 60 seconds.
- **Zero-second cooldown:** one editable command per channel can use `0`. New channels already give that slot to `!s`, so another command can't use `0` until `!s` changes.
- **Who can use it:** choose one method per command. **User level** uses one level, such as Subscribers or Mods. **Tags and accounts** lets you allow or exclude groups, and add specific Twitch accounts. The two methods don't combine.

## Keywords (no `!`)

A keyword replies when a word appears in chat, so viewers don't need to type `!`. On the dashboard, use **New keyword** and choose a match rule:

- **Starts with:** the message begins with the word.
- **Anywhere:** the word appears anywhere in the message.
- **Exact:** the whole message is the word.

Keywords always wait at least your plan's minimum cooldown. They don't appear in `!commands`.

## Repeating messages (timers)

Repeating messages post on a timer while your channel is live. Moderators can manage them with `!cct`, `!ect`, and `!dct`, or with `!timer create`, `!timer edit`, `!timer delete`, and `!timer list`. `!timers` works the same way.

```text
!cct socials 15 Check out the channel links!
!ect socials 30 Updated links are in the panels.
!dct socials
!timer list
```

| Plan | Intervals | Active timers |
|------|-----------|---------------|
| Free | `10`, `20`, `30`, `40`, `50`, or `60` minutes | `5` |
| Premium | Multiples of `5` from `5` to `180` minutes | `15` |
| Pro | Any whole number of minutes from `1` to `180` | `50` |

- **Name:** up to `30` characters: letters, numbers, and underscores.
- **Message:** up to `350` characters. Timer messages can use `$(...)` functions.
- **Interval:** a number of minutes, or add `m` or `h` (for example `15m` or `1h`).
- **Plan change:** if an interval is no longer allowed after a plan change, the timer keeps running. Choose an allowed interval before you edit it again.

## Write a reply

Replies use `$(...)` functions for dynamic text. The bot does not replace `{user}`-style placeholders.

| You write | The bot inserts |
|-----------|-----------------|
| `$(user)` | The viewer's name |
| `$(twitch.channel)` | Your channel name |
| `$(twitch.game)` | The current game |
| `$(random 10)` | A random number from 0 to 9 |
| `&p1`, `&p2` | The first and second word after the command |
| `&t` | The rest of what the viewer typed |

For counters, conditions, and more functions, see the [advanced command guides](/commands/advanced/).

## Examples

<Tabs>
<TabItem label="Text">

Plain text for info, links, and rules.

```
!cc discord Check out my Discord! discord.gg/example
```

**Chat:**
```
💬 Viewer: !discord
🤖 DomDimaBot: Check out my Discord! discord.gg/example
```

</TabItem>
<TabItem label="Functions">

Use `$(...)` functions when the reply should change.

```
!cc gameinfo $(twitch.channel) is currently playing $(twitch.game)
```

**Chat:**
```
💬 Viewer: !gameinfo
🤖 DomDimaBot: DomDima is currently playing Valorant
```

</TabItem>
<TabItem label="Arguments">

Use `&p1`, `&p2`, and `&t` to use what the viewer types after the command.

```
!cc hug $(user) sends a warm hug to &p1! 🤗
```

**Chat:**
```
💬 Viewer: !hug @FriendUser
🤖 DomDimaBot: Viewer sends a warm hug to @FriendUser! 🤗
```

```
!cc say $(user) says: &t
```

**Chat:**
```
💬 Viewer: !say this bot is amazing
🤖 DomDimaBot: Viewer says: this bot is amazing
```

</TabItem>
<TabItem label="Counters">

Variables are ones you create. They don't exist until you set them.

```
!cc wins *(^(#wins) ? %(#wins *(%(#wins) + 1)) : %(#wins 1)) $(user) total wins: %(#wins)
```

**Chat:**
```
💬 Viewer: !wins
🤖 DomDimaBot: Viewer total wins: 1
```

Each later use adds one.

</TabItem>
<TabItem label="Triggers and other commands">

A reply can play a trigger or run another command.

```
!cc airhorn $(trigger.send airhorn) AIRHORN!
```

If a trigger named `airhorn` exists, it plays when the command runs.

```
!cc creator Check out my links here: #(discord)
```

This runs the `discord` command inside `creator`.

</TabItem>
</Tabs>

<Aside type="tip">
You can also use the **Commands** page on the dashboard to see every command, its status, and its access level in one place.
</Aside>
