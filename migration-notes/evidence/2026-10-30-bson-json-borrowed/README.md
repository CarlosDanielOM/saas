# Borrowed BSON JSON serializer evidence

This package supports [the borrowed serializer note](../../bson-js-json-borrowed.md). It binds results to accepted code commit `9d4971e70831e98a5e135dee96b0d3866d8a6787` and frozen source tree SHA-256 `1eb7124e14ac30149213b98485793be3e50985f60782f2643e1723ba39e788b5`. [source-bindings.json](source-bindings.json) lists the five direct source/test files captured byte-for-byte with `git show`, all 14 benchmark source pins, the SDK pins, reference fixture identity, and the full-tree digest. It also embeds the ten reused SDK hashes and the hash of the upstream `cache-and-types.archiveVerifiedSdkInputs` binding. The package intentionally does not clone the full source tree. Each captured direct file matches its corresponding frozen benchmark source pin.

`artifacts/reference/` retains the 54-record pinned SDK reference fixture. `artifacts/benchmark2/` and `artifacts/benchmark3/` each retain the exact prepared input and Node, Rust-owned, and Rust-borrowed reports. Both rounds used input SHA-256 `b719d74652c2104c1a2126b4757d70d3f5df094ba34ac07595bca01871dae89c`; the facts include the per-workload medians, ranges, overlap flags, and compiler resource limits. `artifacts/owned-baseline/` retains the prior owned input and actor reports to keep both owned regressions auditable. `benchmark-executable.gz` preserves the benchmark-only executable.

`runs/` contains compressed raw receipts and logs for format run `format-1793354597395156983`, Node runs `node-1793354782214257150`, `node-1793355106222674223`, `node-1793355171538637514`, and `node-1793355306882075343`, and compiler runs `compiler-1793354853734987168` and `compiler-1793355240844334800`. For every `.gz` item, `artifact-sha256.json` records the stored compressed SHA-256 and the raw SHA-256 and byte length after decompression. The copied final facts and production readback are under `artifacts/`.

`reproduction-tools/` contains static copies of the recorded freezer chain, validator, formatter, readback, benchmark setup, and exact-check launchers. They were copied as evidence and were not executed during this documentation task. No tool, application, test, formatter, container, network, deployment, or push was run by this documentation author.

`artifact-sha256.json` indexes every payload in this package except itself. It was produced by static file copying and hashing; the compressed executable and run records are verified in both stored and decompressed form. The prior owned-baseline note and evidence are also linked from the [borrowed results note](../../bson-js-json-borrowed.md) and [baseline note](../../bson-js-json-benchmark.md).
