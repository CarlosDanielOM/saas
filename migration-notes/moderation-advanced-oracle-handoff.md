## What source discovery establishes

The TypeScript route calls `sanitizeRule`, which parses an advanced rule before variation and general type validation. The handler calls `findBlacklistMatches` only for blacklist rules, and the schema persists pattern and semantic fields. Literal handling can reuse `compileBlacklistPattern` and `foldText`; `JsString` and lossless JSON preserve UTF-16 and number bits. Existing `re2_compat.rs` accepts UTF-8 strings and does not establish lone-surrogate parity. The source-built SDK probes, not assumptions about Rust regex or JavaScript regexes, are the evidence for observed SDK behavior.

The Unicode wrapper header declares Unicode 17.0.0, while vendored RE2 category and fold tables have no declared version. The measurements show concrete differences between wrapper and native facts. The string probe found 27 mismatches against the earlier lossy-UTF-8 candidate; the bounded capacity candidate matched the 1,472 recorded observations. Arbitrary malformed capture byte strings remain unproven. Refer to the [codec](re2-string-handoff.md) and [Unicode](re2-unicode-handoff.md) handoffs for their exact scopes.
