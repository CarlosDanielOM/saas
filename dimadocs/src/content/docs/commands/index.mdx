DomDimaBot commands let a channel run built-in actions and streamer-authored chat responses. The commands available in a channel depend on its command configuration and each command's enabled and permission settings.

The `!commands` chat command lists enabled commands that the current chatter is allowed to use. The dashboard also has a Commands page for managing a channel's custom commands.
