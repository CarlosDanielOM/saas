Invalid executable prototypes/hooks, `undefined`, and sparse-array identity are outside the owned JSON boundary. Typed categories intentionally use closed known types; JSON adapters represent ordinary unvalidated data.

`spam_rule_template` and `spam_rule_view` expose borrowed template/example identity. `spam_rule()` copies the semantic `Vec` because the existing shared `SemanticPolicy` uses owned vectors; arbitrary mutable JavaScript example sharing is a bounded gap. Rule base `Arc` fields preserve shared native references.

Mongo driver retry behavior is caller-owned, matching the source Mongoose client; the service adds no application-level retry. Context ordinary-JSON regex coercion uses the shared JS conversion helper, including own `toString` errors; executable prototype/accessor hooks are outside that boundary. `Date` identity in ordinary JSON output is not modeled. Lua uses server `TIME` and the exact global key; its literal is checked against the TypeScript source.
