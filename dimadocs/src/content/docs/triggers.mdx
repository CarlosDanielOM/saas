Triggers play a sound or video on your stream. Use them for airhorns, sound effects, and clips you want to play on demand. A trigger can run from a Channel Points reward, a chat command, or the **Test** button. The Triggers module is available on every plan. You need the **Triggers and media** permission: be the channel owner or an admin with that permission.

## Set up the OBS source

1. Open **Modules → Triggers** and select **Copy** next to **Overlay URL for OBS**.
2. In OBS, add a **Browser** source, paste the URL, and set its size to **1920×1080**. Every trigger plays in this one source.
3. Keep the source open while you stream.
4. Back on the dashboard, select **Test** on a trigger. The test dialog has its own preview, so you can check playback without OBS open.

## Add media and create a trigger

1. Upload a file to the [Media Library](/media-library/), or add one from the public library.
2. Fill in the trigger, then select **Create trigger**:
   - **Trigger name**: letters, numbers, and underscores, starting with a letter, up to 60 characters. Example: `Airhorn` or `Hydrate_Check`.
   - **Volume**.
   - **Create a channel points reward** (optional). See below.

Triggers play audio and video. Images and GIFs can be in your library, but you cannot use them as triggers. Free channels upload to the public library. Premium and Pro channels can keep files private. File size and storage limits are in the [Media Library](/media-library/).

After a trigger is created, its media cannot be swapped. Create a new trigger to use a different file.

## Ways to play a trigger

- **Dashboard test:** Select **Test** on a trigger. The test needs a connected trigger client: the dashboard preview or the OBS source.
- **Chat command:** Use `$(trigger.send trigger_name)` in a command or reward message. For example, `$(trigger.send airhorn)`. The trigger must exist and be enabled. If it does not, the command replies with a message instead of playing.
- **Channel Points reward:** Turn on **Create a channel points reward** in the trigger editor, then set:
  - **Reward name** and **Cost (points)**.
  - **Description viewers see**.
  - **Runs when redeemed**. It starts as `$(trigger.send name)`. You can add more text, such as a chat message.

  Viewers who redeem the reward play the trigger. Deleting a trigger also removes its reward from Twitch.

## Troubleshooting

- **Test says it could not send the trigger:** Make sure the OBS Browser source is open, uses the copied URL, and is set to 1920×1080. Refresh the browser source, then test again.
- **Nothing plays on stream:** Check that the source is active in the current scene and that the trigger is enabled.
- **Want Bits-based sounds for viewers?** Use [DimaFX](/dimafx/). DimaFX uses its own OBS source, so it does not play through the Triggers source.
