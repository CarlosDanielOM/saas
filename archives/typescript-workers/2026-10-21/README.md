# Retired TypeScript worker entrypoints

This archive preserves the five previously accepted TypeScript worker entrypoints and the raid-sessions entrypoint removed from the cron source tree. Their original paths, source digests, and base commit are recorded in [`manifest.json`](manifest.json).

The archived files preserve their original bytes and import paths. They are historical source only: the archive is outside the application build and Docker image, and its files are not executable in place. The five previously accepted responsibilities use their native Rust binaries in both the Node cron runtime and `tsx` development. Raid sessions is the sixth source integration; all eight exact-image suites passed 102 groups and production acceptance passed on candidate `cron-7a8ca7924412`. Former `*_RUNTIME=typescript` keys are retired only for workers that historically had those selectors; no `RAID_SESSIONS_RUNTIME` selector existed and any similarly named fixture key is ignored. Native startup or process failure is handled by the supervisor's same-worker Rust restart, with no TypeScript fallback. `cron:dev` with `CRON_WORKER_RUNTIME=tsx` requires all six native binaries at the paths defined by native worker metadata under `/usr/local/bin/`; missing binaries are reported/retried as Rust children without TypeScript substitution.

The current Rust-only policy requires all six native worker behavior suites and a seventh retirement check on each cron candidate; the raid-sessions candidate also passed its pipeline check for eight exact-image checks total. To intentionally restore any TypeScript worker, manually copy the required original file to its recorded path, review the supervisor registration and corresponding tests, and revise the matching Rust-only retirement assertions that require its absence. Preserve all six workers' functional coverage and verify the updated candidate before deployment. There is no automatic archive restore command, selector, fallback flag, or quick restore script. Follow the current policy and release record in [`migration-notes/typescript-worker-retirement.md`](../../../migration-notes/typescript-worker-retirement.md).

The archive covers six scheduled entrypoints: stream activity; raid analytics; follow-defense **baseline**; roulette **completion**; AI usage receipts; and raid sessions. Other TypeScript cron workers, producers, APIs, utilities, and the `roulette-actions` child remain active. Some shared TypeScript helpers serve both APIs and parity fixtures; retained helpers and fixtures do not provide a scheduled worker runtime or fallback.
