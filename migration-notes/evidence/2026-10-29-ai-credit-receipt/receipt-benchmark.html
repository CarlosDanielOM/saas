Baseline Rust took 5.741841206 µs/op, 8.895% more time than TypeScript. Optimized Rust takes 4.931949913 µs/op: 14.105% less time than baseline Rust.

What these measurements cover

Timed: prepared receipt construction, JSON encoding, and summing UTF-8 bytes. Each trial has 262,144 operations, except large payloads with 32,768. Every workload has 32,000 warmup operations.

Outside the timed region: Redis, setup, parsing, and clock I/O. CPU usage, RSS, and full API latency were not measured. Every timed input has entryKind: usage; adjustment correctness is covered elsewhere and is not timed.

Medians and min–max ranges come from all seven retained trials. Ranges describe observed variation, not confidence intervals. The ratios divide the TypeScript median by the optimized Rust median; they apply only to these workloads.

Trial reuse: the same seven actual TypeScript trials per workload are retained unchanged in both reports. Only the native core provenance hash was rebound; the prepared payloads, expected wires, checksums, TypeScript source, and harness are unchanged. Baseline and final Rust trials are both retained.
