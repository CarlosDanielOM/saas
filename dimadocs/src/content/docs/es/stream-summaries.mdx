Después de que termina un stream, DomDimaBot puede escribir una recapitulación corta y guardar lo que aprendió como memorias. **Módulos → Resúmenes de Directo** muestra tus streams anteriores con sus números, la recapitulación y los cambios de memoria hechos a partir de cada uno. Está disponible en todos los planes.

Para ver la lista necesitas el permiso `summaries:view`. Para aprobar o cambiar las memorias que propone necesitas `memories:manage`.

## Activar los resúmenes

<Steps>

1. Abre **Módulos → Personalidad IA**.
2. En **Activar o desactivar**, activa **Resumenes de stream**.
3. En **Mantenimiento automático**, activa **Aprender después de cada directo**. Los dos interruptores deben estar activados.
4. Deja activado **Aprender del chat** si quieres que el bot guarde memorias de cada recapitulación. Sin él, la recapitulación se escribe igual, pero no se guarda ninguna memoria.
5. Selecciona **Guardar cambios**.
6. Cuando termine tu próximo stream, abre **Módulos → Resúmenes de Directo**. La primera recapitulación suele aparecer unos minutos después de que termine el stream.

</Steps>

El interruptor **Chat IA activado** controla solo las respuestas del chat. No activa ni desactiva los resúmenes.

## Cuándo se escribe una recapitulación

Solo se escribe una recapitulación para un stream lo bastante largo y activo. Por defecto, un stream necesita al menos **20 minutos** y **30 mensajes** en el chat. Si no llega a cualquiera de los dos mínimos, muestra **Demasiado corto** y no genera recapitulación ni cambios de memoria.

Puedes cambiar ambos mínimos en **Ajustar los números** de [Personalidad IA](/es/ai-personality/).

Las limpiezas semanales y mensuales también aparecen en la lista cuando esos interruptores están activados, con los nombres **Limpieza semanal de memorias** o **Limpieza mensual de memorias**.

## Leer un stream

Selecciona un stream de la lista. Los detalles muestran:

- **Duración**, **Media de espectadores** y **Pico**.
- **Follows**, **Subs**, **Bits** y **Propinas**.
- **Qué pasó**: el título, la recapitulación y los momentos destacados.
- **Qué aprendió el bot**: cada cambio de memoria, con el **Por qué:** y la evidencia del chat (**Del chat**) en la que se basa.

Cada cambio de memoria muestra un resultado:

| Resultado | Significado |
|---|---|
| **Guardada** | Se creó, actualizó, archivó o eliminó la memoria. |
| **No se pudo guardar** | El cambio falló. |
| **No guardada: el aprendizaje está apagado** | **Aprender del chat** está desactivado. |
| **No guardada: el bot no estaba lo bastante seguro** | La confianza fue menor que el umbral de esa acción. |
| **No guardada: el guardado automático está apagado para esto** | El interruptor automático correspondiente está desactivado. |
| **No guardada: se alcanzó el límite por stream** | El stream llegó al máximo de cambios. |
| **Se mantiene: aún se usa** | Se omitió una eliminación porque la memoria se usó o actualizó hace poco. |

## Estado del stream

| Etiqueta | Significado |
|---|---|
| **Escribiendo…** | La recapitulación no ha terminado. Vuelve en unos minutos. |
| **N memorias guardadas** | Se guardó al menos un cambio de memoria. No tienen que guardarse todas las propuestas. |
| **Nada nuevo que recordar** | El bot terminó y no encontró nada que valiera la pena guardar. |
| **Demasiado corto** | El stream no llegó al mínimo de duración o de mensajes del chat. |
| **Sin cambios necesarios** | Una limpieza no encontró nada que cambiar. |
| **No se pudo terminar** | El procesamiento falló. El próximo stream se resumirá con normalidad. |

## Límites

- La recapitulación y las sugerencias de memoria las genera un modelo de IA a partir de una muestra del chat y de los datos del stream. Pueden omitir eventos, interpretar mal el contexto o contener errores. Úsalas para ayudarte a revisar, no como transcripción completa.
- El procesamiento puede demorarse o fallar si los datos o el proveedor de IA no están disponibles.
- Si tu cuenta de Twitch está activa y tiene un correo registrado, el bot envía la recapitulación por correo cuando el resumen termina bien.
- Generar resúmenes cuenta para el uso de IA de tu canal. Consulta [Planes](/es/plans/) para ver las asignaciones.

Para ver las asignaciones de cada plan, consulta [Planes](/es/plans/). Para revisar memorias y los controles de aprendizaje, consulta [Memorias](/es/memories/) y [Personalidad IA](/es/ai-personality/).
