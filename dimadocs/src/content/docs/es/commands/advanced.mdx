AST es la capa avanzada detrás de los comandos personalizados. Te permite que un comando recuerde valores, tome decisiones, llame funciones y ejecute otros comandos. Úsalo cuando una respuesta fija no alcanza.

<Aside type="caution">
Esta sección es para configuraciones avanzadas. Si basta con una respuesta fija, empieza por [Comandos](/es/commands/overview/).
</Aside>

## ¿Necesitas AST?

Un mensaje de comando es texto plano por defecto. Cuando usa un prefijo de AST (`$(`, `%(`, `*(`, `^(`, `%del(` o `#(`), esa parte se ejecuta como AST.

| El texto plano basta cuando... | Usa AST cuando... |
|--------------------------------|-------------------|
| La respuesta nunca cambia | La respuesta tiene un número que cambia, como un contador |
| Solo necesitas un enlace o una frase fija | Necesitas recordar algo entre usos |
| | Necesitas lógica if/else, un elemento al azar o un bucle |
| | Quieres que el comando llame una función u otro comando |

**Texto plano** (sin AST):

```bash
Únete a nuestro Discord: example.com/discord
```

**AST** (un contador que cambia cada vez):

```bash
*( ^(#wins) ? %(#wins *(%(#wins) + 1)) : %(#wins 1) ) $(user) tiene %(#wins) wins!
```

Qué hace:

1. Comprueba si `#wins` existe.
2. Si existe, le suma 1. Si no, lo crea con `1`.
3. Muestra el total actualizado, por ejemplo `Carlos tiene 3 wins!`.

<Aside type="note">
`#wins` es una variable de caché. Expira 24 horas después de su último cambio. Para un contador que debe durar, usa una variable de base de datos (`*wins`), que requiere Premium o Pro.
</Aside>

## Importante: las variables no vienen creadas

DomDimaBot **no** crea variables AST por ti.

- Creas una variable escribiéndola: `%(nombre valor)`.
- Los datos de contexto vienen de **funciones** como `$(user)` y `$(twitch.game)`, o de **argumentos** como `&p1`.

```bash
%(#wins *(%(#wins) + 1)) $(user) ahora tiene %(#wins) wins!
```

## Para qué sirve AST

- guardar contadores y progreso de usuarios
- construir respuestas que cambian
- ejecutar lógica if / else
- trabajar con listas y bucles
- llamar funciones de Twitch, moderación, disponibilidad, TTS, ruleta, triggers y EventSub
- programar acciones AST con delay que sobreviven reinicios del bot
- encadenar comandos entre sí

## Modelo mental rápido

Piensa en los comandos AST como pequeños scripts dentro de un comando personalizado.

- `%(...)` = leer o escribir tus variables
- `%del(...)` = borrar una variable o un elemento de lista
- `$(...)` = llamar una función
- `*(...)` = calcular lógica, o ejecutar un bucle
- `^(...)` = comprobar si algo existe
- `#(...)` = ejecutar otro comando desde este comando

## Funciones según el plan

Algunas funciones AST dependen del plan del streamer.

| Función | Free | Premium | Pro |
|---------|------|---------|-----|
| Variables en memoria | Sí | Sí | Sí |
| Variables de caché (`#`, `##`) | Sí | Sí | Sí |
| Variables de base de datos (`*`, `**`) | Las escrituras se ignoran | Sí | Sí |
| Bucles anidados uno dentro de otro | 2 | 3 | 4 |
| Iteraciones por bucle | 25 | 50 | 100 |

<Aside type="note">
Las escrituras en variables de base de datos requieren Premium o Pro. Los valores de caché expiran 24 horas después de cada escritura. Consulta [Variables y almacenamiento](/es/commands/advanced/syntax/#variables-y-almacenamiento) para más detalles.
</Aside>

## Flujo recomendado

1. Empieza con una respuesta de texto plano
2. Añade argumentos como `&p1`
3. Añade funciones como `$(user)` o `$(twitch.game)`
4. Añade variables solo cuando necesites estado
5. Añade condicionales y bucles al final

<Aside type="tip">
Si un comando AST puede banear usuarios, dar roles, cambiar el título o juego, iniciar encuestas o activar media, mantenlo restringido a moderadores o al broadcaster.
</Aside>
