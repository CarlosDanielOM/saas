Functions are called with `$(...)`.

```bash
$(user)
$(random 10)
$(twitch.game)
```

<Aside type="note">
Some functions only read data. Others perform actions like banning, changing title, speaking TTS, or sending chat messages. Restrict action-heavy commands to trusted roles.
</Aside>

## User functions

| Function | Description | Usage |
|----------|-------------|-------|
| `$(user)` | Current chatter's username | `$(user)` |
| `$(touser)` | Target user from context | `$(touser)` |
| `$(randomuser)` | Random chatter in channel | `$(randomuser)` |

## Random functions

| Function | Description | Usage |
|----------|-------------|-------|
| `$(random N)` | Random integer from `0` to `N-1` | `$(random 10)` |
| `$(random)` | Random integer using the default range | `$(random)` |

## String functions

| Function | Description | Usage |
|----------|-------------|-------|
| `$(upper text)` | Uppercases the text | `$(upper hello)` → `HELLO` |
| `$(lower text)` | Lowercases the text | `$(lower HELLO)` → `hello` |
| `$(title text)` | Capitalizes each word | `$(title hello world)` → `Hello World` |
| `$(capitalize text)` | Capitalizes only the first letter | `$(capitalize hello)` → `Hello` |
| `$(trim text)` | Removes surrounding whitespace | `$(trim "  hi  ")` → `hi` |
| `$(length text)` | Length of the text | `$(length hello)` → `5` |
| `$(slice start [end] text)` | Cuts text by position; negatives wrap from the end | `$(slice 0 5 hello world)` → `hello` |
| `$(replace search replacement text)` | Replaces every occurrence (literal, no regex) | `$(replace o 0 foo)` → `f00` |

For multi-word search or replacement values, use quotes: `$(replace "old text" "new text" the old text here)`.

## Moderation functions

| Function | Description | Args | Access notes |
|----------|-------------|------|--------------|
| `$(vip)` or `$(add.vip)` | Add VIP | `username [days]` | Mod |
| `$(unvip)` | Remove VIP | `username` | Mod |
| `$(ban)` | Ban or timeout user | `username [duration_seconds]` | Mod |
| `$(ban.mod)` | Remove a moderator, then ban/timeout them; optionally restore mod after a timeout | `username seconds [true|false]` | Requires level 8 for AI calls; authored commands use configured command permissions |
| `$(mod)` or `$(add.mod)` | Add moderator | `username [days]` | Requires level 8 for AI calls; authored commands use configured command permissions |
| `$(unmod)` | Remove moderator | `username` | Requires level 8 for AI calls; authored commands use configured command permissions |
| `$(clear.chat)` | Clear chat | none | Mod |
| `$(emoteonly)` | Toggle emote-only mode | `[duration_seconds]` | Mod |
| `$(bot.mode attack)` | Manually activate Follow Defense Attack Mode | none | Mod |
| `$(bot.mode status)` | Show current Follow Defense mode | none | Mod |
| `$(permit [username] [seconds])` | Temporarily bypass channel moderation filters; without arguments permits everyone for 60 seconds | `[username] [seconds]` | Mod |

Temporary mod and VIP durations from `1` to `365` days require **Premium or Pro**. Pin, moderation, and channel actions are checked against function permissions for AI calls; streamer-authored commands are governed by their configured command access.

<Aside type="caution">
`$(bot.mode attack)` can permanently ban tracked followers from an active follow wave. Use it only in moderator-only commands such as `!defmode`. See [Follow Defense](/follow-defense/) for details.
</Aside>

## Channel functions

| Function | Description | Usage |
|----------|-------------|-------|
| `$(raid channel)` | Raid target channel | `$(raid targetchannel)` |
| `$(unraid)` | Cancel raid | `$(unraid)` |
| `$(set.title new_title)` | Update stream title | `$(set.title Playing Valorant!)` |
| `$(set.game game_name)` | Update category | `$(set.game Valorant)` |
| `$(start.prediction "title;opt1/opt2;seconds")` | Start prediction; quote the complete semicolon-separated argument | `$(start.prediction "Who wins?;A/B;120")` |
| `$(start.poll "title;opt1/opt2;seconds")` | Start poll; quote the complete semicolon-separated argument | `$(start.poll "Favorite game?;COD/Halo;60")` |
| `$(ad)` | Ad duration in seconds | `$(ad)` |
| `$(ad.time)` | Ad duration in seconds | `$(ad.time)` |
| `$(ai prompt)` | AI-generated response | `$(ai tell a joke)` |

### Polls and predictions

These functions require moderator access in streamer-authored commands. Quote the entire `title;options;seconds` argument because semicolons are reserved syntax. Use `/` between choices.

| Function | Description | Usage |
|----------|-------------|-------|
| `$(start.poll "title;choice1/choice2;seconds")` | Start a poll with 2–5 choices | `$(start.poll "Best map?;Nuke/Mirage;120")` |
| `$(get.poll)` | Read the active poll, or the latest poll if none is active; includes status and vote totals | `$(get.poll)` |
| `$(end.poll)` | End the active poll and archive its results | `$(end.poll)` |
| `$(cancel.poll)` | End the active poll without archiving its results | `$(cancel.poll)` |
| `$(start.prediction "title;choice1/choice2;seconds")` | Start a channel-points prediction with 2–10 choices | `$(start.prediction "Will we win?;Yes/No;120")` |
| `$(get.prediction)` | Read the active or locked prediction and its numbered choices | `$(get.prediction)` |
| `$(lock.prediction)` | Close betting without choosing a winner; already locked predictions stay locked | `$(lock.prediction)` |
| `$(end.prediction option)` | Resolve with an exact choice title or its 1-based number | `$(end.prediction "No")` or `$(end.prediction 1)` |
| `$(cancel.prediction)` | Cancel the active or locked prediction without choosing a winner | `$(cancel.prediction)` |

Call `get.prediction` before ending one so you can check the question and actual choice order. `end.prediction` fetches the current prediction again and rejects missing, ambiguous, or invalid choices.

## Availability functions

Moderators can enable or disable one of their custom commands or Twitch channel-point rewards. Names are matched exactly without case sensitivity; for commands, the leading `!` is optional. For rewards, use the exact title or reward ID when titles are ambiguous.

| Function | Description | Usage |
|----------|-------------|-------|
| `$(disable.command "name" [seconds])` | Disable a command, optionally restoring its prior state later | `$(disable.command spoilers 300)` |
| `$(enable.command "name" [seconds])` | Enable a command, optionally restoring its prior state later | `$(enable.command spoilers 300)` |
| `$(disable.redemption "title-or-id" [seconds])` | Disable a Twitch redemption, optionally restoring its prior state later | `$(disable.redemption "Hydrate" 300)` |
| `$(enable.redemption "title-or-id" [seconds])` | Enable a Twitch redemption, optionally restoring its prior state later | `$(enable.redemption "Hydrate" 300)` |

The optional duration is a whole number of seconds from `1` to `604800` (seven days). When it expires, the item returns to the state it had before the timed change, including after a bot restart. Repeating the same timed change extends the deadline. Omitting the duration cancels any pending restoration. Quote names that contain spaces.

## Roulette functions

These AST controls require **Pro**. Identify a roulette by its saved alias or ID; operations that omit it use the active roulette. Except for `result` and `add`, these functions return no chat text. `add` returns the new item ID, which you can save in an AST variable.

| Function | Description | Usage |
|----------|-------------|-------|
| `$(roulette.add roulette_id "item label" [multiplier] [weight])` | Add copies of an item; multiplier and weight default to 1 | `$(roulette.add giveaways "VIP for a day" 3 10)` |
| `$(roulette.remove roulette_id item_id)` | Remove an item and all its copies | `$(roulette.remove giveaways item_id)` |
| `$(roulette.update roulette_id item_id multiplier [weight])` | Change an item's copy count and optionally its weight | `$(roulette.update giveaways item_id 3 10)` |
| `$(roulette.shuffle roulette_id)` | Shuffle copies without changing their odds | `$(roulette.shuffle giveaways)` |
| `$(roulette.switch roulette_id)` | Select the active roulette without changing visibility | `$(roulette.switch giveaways)` |
| `$(roulette.show)` / `$(roulette.hide)` | Show or hide the overlay; hiding does not cancel a draw | `$(roulette.show)` |
| `$(roulette.start [roulette_id])` | Start the active or named roulette and record a winner | `$(roulette.start giveaways)` |
| `$(roulette.result [roulette_id])` | Return the most recently completed winner label, or blank if there is none | `$(roulette.result giveaways)` |

You can attach an AST action to an item in the roulette editor. It runs when that item wins, with `%(roulette_id)`, `%(roulette_draw_id)`, `%(roulette_item_id)`, and `%(roulette_item)` available. Restrict who can start a draw when winner actions can change channel state.

## EventSub functions

These only return useful data when the command is triggered by the matching EventSub event.

| Function | Event Context | Returns |
|----------|---------------|---------|
| `$(raid.channel)` | `channel.raid` | Raiding channel display name |
| `$(raid.login)` | `channel.raid` | Raiding channel login |
| `$(raid.viewers)` | `channel.raid` | Number of raid viewers |
| `$(cheer.amount)` | `channel.cheer` | Bits cheered |
| `$(cheer.message)` | `channel.cheer` | Cheer message text |
| `$(sub.tier)` | `channel.subscribe` | Prime / Tier 1 / Tier 2 / Tier 3 |
| `$(sub.months)` | `channel.subscribe` | Cumulative months |
| `$(gifted.user)` | `channel.gift` | Gift recipient username |
| `$(hypetrain.progress)` | `hypetrain.event` | Progress toward goal |
| `$(hypetrain.level)` | `hypetrain.event` | Current level |
| `$(hypetrain.end)` | `hypetrain.event` | End timestamp |
| `$(shoutout.channel)` | `channel.shoutout` | Channel that was shouted out |
| `$(reward.input)` | `channel.points_redemption` | User redemption input |
| `$(redemption.input)` | `channel.points_redemption` | User redemption input |
| `$(ad)` | `channel.ad_break` | Ad duration |

## Pinned chat messages

| Function | Description | Usage |
|----------|-------------|-------|
| `$(pin [duration] message)` / `$(pin.create ...)` | Send and pin a chat message; optional duration is 30–1800 seconds | `$(pin.create 300 Rules: be kind)` |
| `$(pin.update seconds)` | Change the current pin duration (30–1800 seconds) | `$(pin.update 600)` |
| `$(pin.del)` / `$(pin.delete)` | Unpin the current chat message | `$(pin.del)` |

These actions require moderator level access.

## TTS functions

TTS calls run inside the custom command's AST and use that command's configured access. The default calls speak with the channel's configured TTS voice. `tts.clone`/`tts.fish` use a Fish Audio voice available to the channel, while `set.voice` changes the default channel voice and provider.

| Function | Plan | Description | Usage |
|----------|------|-------------|-------|
| `$(tts message)` | Depends on channel TTS settings and plan | Queue default TTS | `$(tts Hello world)` |
| `$(tts.speak message)` | Depends on channel TTS settings and plan | Same as `$(tts ...)` | `$(tts.speak Hello)` |
| `$(tts.ai message)` | Depends on channel TTS settings and plan | Same as `$(tts ...)` | `$(tts.ai Hello world)` |
| `$(tts.clone name message)` | Depends on TTS settings and plan | Speak with a named Fish Audio voice | `$(tts.clone voice1 Hello)` |
| `$(tts.fish name message)` | Depends on TTS settings and plan | Alias of `$(tts.clone ...)` | `$(tts.fish voice1 Hello)` |
| `$(set.voice voice_name)` | Moderator action; choose one of the four built-in Fish voices or a saved favorite, and switch the channel provider to Fish | `$(set.voice gojo)` or `$(set.voice favorite_alias)` |

## Trigger functions

| Function | Description | Usage |

| `$(trigger.send name)` | Fire a trigger | `$(trigger.send airhorn)` |
| `$(trigger.send name true)` | Fire a queued trigger | `$(trigger.send airhorn true)` |

## Delay, control, and chat functions

| Function | Description | Usage |
|----------|-------------|-------|
| `$(delay N)` | Pause for `N` seconds, max `60` | `$(delay 5)` |
| `$(break)` | Exit a loop early | `$(break)` |
| `$(continue)` | Skip the current loop iteration | `$(continue)` |
| `$(chat.send message)` | Send a message to chat | `$(chat.send Hello everyone!)` |
