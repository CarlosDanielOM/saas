Los comandos de DomDimaBot permiten ejecutar acciones integradas y respuestas de chat creadas por el streamer. Los comandos disponibles en cada canal dependen de su configuración y de los ajustes de activación y permisos de cada comando.

El comando de chat `!commands` muestra los comandos activados que el usuario actual tiene permiso para usar. El panel también incluye una página de Commands para administrar los comandos personalizados del canal.
