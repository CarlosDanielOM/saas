The source Redis script is retained; the native quota EVAL is wrapped in the selected `cache` / `eval` telemetry span. This reuses the shared application's manager and telemetry lifecycle; it adds no client cache or worker. Saved and existing-job fast paths, resolution, and job processing do not acquire quota Redis. One source gap remains: the shared native bootstrap does not reproduce arbitrary source console messages, connection-event logging, or all Dragonfly wrapper observability.
