El **parser AST** de DomDimaBot es la capa avanzada detrás de los comandos personalizados. Te permite construir comandos que guardan valores, ejecutan lógica, llaman funciones, reutilizan otros comandos y responden distinto según el contexto.

<Aside type="caution">
Esta sección es para configuraciones avanzadas. Si solo necesitas comandos de texto simples, empieza por [Comandos](/es/commands/overview).
</Aside>

## Para qué sirve AST

Usa AST cuando quieres que un comando haga algo más que enviar texto fijo.

- guardar contadores y progreso de usuarios
- construir respuestas dinámicas
- ejecutar lógica tipo if / else
- trabajar con arrays y bucles
- llamar funciones de Twitch, moderación, TTS, triggers y EventSub
- encadenar comandos entre sí

## Importante: las variables no vienen creadas

DomDimaBot **no** te da variables AST por defecto automáticamente.

- Las variables las **creas tú** con `%(...)`
- Si quieres guardar un valor, debes crear esa variable
- Los datos de contexto normalmente vienen de **funciones** como `$(user)`, `$(twitch.game)` o de **argumentos** como `&p1`

Ejemplo:

```bash
%(#wins *(%(#wins) + 1))
"$(user) ahora tiene %(#wins) wins!"
```

## Modelo mental rápido

Piensa en los comandos AST como pequeños scripts dentro de un comando personalizado.

- `%(...)` = leer o escribir tus variables
- `$(...)` = llamar una función
- `*(...)` = calcular lógica
- `^(...)` = comprobar si algo existe
- `#(...)` = ejecutar otro comando desde este comando

## Ejemplo rápido

Este comando crea un contador simple de wins:

```bash
*( ^(#wins) ? %(#wins *(%(#wins) + 1)) : %(#wins 1) )
"$(user) tiene %(#wins) wins!"
```

Qué hace:

1. comprueba si `#wins` existe
2. si existe, lo incrementa
3. si no existe, lo crea con `1`
4. imprime el total actualizado

## Funciones según el plan

Algunas funciones AST dependen del plan del streamer.

| Función | Free | Premium | Pro |
|---------|------|---------|-----|
| Variables en memoria | Sí | Sí | Sí |
| Variables de caché (`#`, `##`) | Sí | Sí | Sí |
| Variables de base de datos (`*`, `**`) | No | Sí | Sí |
| Bucles más profundos | Limitado | Más | Más aún |
| Voz IA / voice clone | Limitado | Más | Más aún |

## Flujo recomendado

1. Empieza con una respuesta de texto plano
2. Añade argumentos como `&p1`
3. Añade funciones como `$(user)` o `$(twitch.game)`
4. Añade variables solo cuando necesites estado
5. Añade condicionales y bucles al final

<Aside type="tip">
Si un comando AST puede banear usuarios, dar roles, cambiar el título o juego, iniciar encuestas o activar media, mantenlo restringido a moderadores o al broadcaster.
</Aside>
