Los comandos personalizados son respuestas que escribes tú. Cuando alguien escribe `!discord`, el bot responde con tu enlace. Los moderadores pueden crearlos desde el chat o desde el dashboard.

Para lo que el bot ya hace, como `!so` o `!poll`, consulta [Comandos integrados](/es/commands/built-in/).

## Crear un comando

<Tabs>
<TabItem label="Por chat">

Escribe `!cc`, luego el nombre (sin `!`) y después la respuesta:

```
!cc <nombre> <respuesta>
```

**Ejemplo:**
```
😎 Streamer: !cc discord ¡Mira mi Discord! discord.gg/ejemplo
🤖 DomDimaBot: Command discord created
```

**Con opciones:**
```
!cc -cd=300 -ul=tier1 discord ¡Enlace de Discord solo para suscriptores! discord.gg/subonly
🤖 DomDimaBot: Command discord created
```

| Opción | Qué define | Predeterminado |
|--------|------------|----------------|
| `-cd=` | Segundos que deben esperar los espectadores entre usos. Mínimo: Gratis `5`, Premium `3`, Pro `1`. `0` se permite en un solo comando editable por canal. | `10` |
| `-ul=` | Quién puede usarlo. Usa un número del `1` al `10` o un nombre de la tabla. | `1` (todos) |

| Número | Nombre | Quién |
|--------|--------|-------|
| `1` | `everyone` | Cualquiera en el chat |
| `2` | `tier1` | Suscriptores |
| `3` | `tier2` | Subs de nivel 2 |
| `4` | `tier3` | Subs de nivel 3 |
| `5` | `vip` | VIPs |
| `6` | `founder` | Fundadores |
| `7` | `mod` | Moderadores o más |
| `8` | `editor` | Editores o más |
| `9` | `admin` | Admins o más |
| `10` | `broadcaster` | Solo tú (`streamer` también funciona) |

`-ul=7` y `-ul=mod` significan lo mismo.

Mensajes del chat que puedes ver (el bot los muestra en inglés):

- `Command already exists`: el nombre ya está en uso, incluidos los nombres de comandos integrados como `so`.
- `Command cooldown must be 0 or at least N seconds`: el valor de `-cd=` está por debajo del mínimo de tu plan.
- `User level X is invalid`: el valor de `-ul=` no está en la tabla.

</TabItem>
<TabItem label="En el dashboard">

1. Abre **Comandos** en la barra de navegación.
2. Pulsa **Nuevo comando**. Usa **Nueva palabra clave** para palabras que deben activar una respuesta sin `!`.
3. Completa **Nombre** (la palabra después de `!`) y **Respuesta**.
4. Define **Espera entre usos** y **Quién puede usarlo**.
5. Opcional: activa **Repetir este comando con un temporizador** y elige los minutos.
6. Pulsa **Crear**.

</TabItem>
</Tabs>

## Editar, desactivar o eliminar un comando

- **Editar la respuesta:** `!ec <nombre> <nueva respuesta>`.
- **Cambiar solo el tiempo de espera o el acceso:** `!ec -cd=<segundos> <nombre>` o `!ec -ul=<nivel> <nombre>`. Deja fuera la respuesta para conservarla. Pon las opciones antes del nombre.
- **Eliminar:** `!dc <nombre>`. Los comandos integrados no se pueden eliminar.
- **Activar o desactivar:** `!enable <nombre>` o `!disable <nombre>`. El nombre funciona con o sin `!`.

Solo puedes editar o eliminar un comando si tu nivel de acceso es igual o superior al que requiere. Los comandos con reglas de etiquetas o de cuentas solo pueden gestionarlos los moderadores desde el chat, y ahí no se puede usar `-ul=`. Cambia esas reglas desde el dashboard.

## Tiempos de espera y acceso

- **El tiempo de espera es compartido por todo el canal.** Después de que un espectador usa un comando, nadie puede volver a usarlo hasta que termine la espera.
- **Mínimos por plan:** Gratis `5` segundos, Premium `3`, Pro `1`. El formulario del dashboard acepta hasta 60 segundos.
- **Espera de 0 segundos:** un comando editable por canal puede usar `0`. Los canales nuevos ya asignan ese espacio a `!s`, así que otro comando no puede usar `0` hasta que cambies `!s`.
- **Quién puede usarlo:** elige un método por comando. **Nivel de usuario** usa un nivel, como Suscriptores o Moderadores. **Etiquetas y cuentas** permite o excluye grupos y agrega cuentas específicas de Twitch. Los dos métodos no se combinan.

## Palabras clave (sin `!`)

Una palabra clave responde cuando aparece una palabra en el chat, así que los espectadores no necesitan escribir `!`. En el dashboard usa **Nueva palabra clave** y elige una regla de coincidencia:

- **Al inicio del mensaje:** el mensaje empieza con la palabra.
- **En cualquier parte del mensaje:** la palabra aparece en cualquier posición.
- **Mensaje completo:** todo el mensaje es la palabra.

Las palabras clave siempre esperan al menos el mínimo de tu plan. No aparecen en `!commands`.

## Mensajes que se repiten (temporizadores)

Los mensajes que se repiten se publican con un temporizador mientras tu canal está en vivo. Los moderadores pueden gestionarlos con `!cct`, `!ect` y `!dct`, o con `!timer create`, `!timer edit`, `!timer delete` y `!timer list`. `!timers` funciona igual.

```text
!cct redes 15 ¡Mira los enlaces del canal!
!ect redes 30 Los enlaces actualizados están en los paneles.
!dct redes
!timer list
```

| Plan | Intervalos | Temporizadores activos |
|------|------------|------------------------|
| Gratis | `10`, `20`, `30`, `40`, `50` o `60` minutos | `5` |
| Premium | Múltiplos de `5` desde `5` hasta `180` minutos | `15` |
| Pro | Cualquier número entero de minutos desde `1` hasta `180` | `50` |

- **Nombre:** hasta `30` caracteres: letras, números y guiones bajos.
- **Mensaje:** hasta `350` caracteres. Los mensajes pueden usar funciones `$(...)`.
- **Intervalo:** un número de minutos, o agrega `m` o `h` (por ejemplo `15m` o `1h`).
- **Cambio de plan:** si un intervalo deja de estar permitido, el temporizador sigue funcionando. Elige un intervalo permitido antes de editarlo de nuevo.

## Escribir una respuesta

Las respuestas usan funciones `$(...)` para texto dinámico. El bot no reemplaza marcadores tipo `{user}`.

| Escribes | El bot inserta |
|----------|----------------|
| `$(user)` | El nombre del espectador |
| `$(twitch.channel)` | El nombre de tu canal |
| `$(twitch.game)` | El juego actual |
| `$(random 10)` | Un número aleatorio del 0 al 9 |
| `&p1`, `&p2` | La primera y la segunda palabra después del comando |
| `&t` | El resto de lo que escribió el espectador |

Para contadores, condiciones y más funciones, consulta las [guías de comandos avanzados](/es/commands/advanced/).

## Ejemplos

<Tabs>
<TabItem label="Texto">

Texto simple para información, enlaces y reglas.

```
!cc discord ¡Mira mi Discord! discord.gg/ejemplo
```

**En el chat:**
```
💬 Espectador: !discord
🤖 DomDimaBot: ¡Mira mi Discord! discord.gg/ejemplo
```

</TabItem>
<TabItem label="Funciones">

Usa funciones `$(...)` cuando la respuesta deba cambiar.

```
!cc infojuego $(twitch.channel) está jugando ahora mismo a $(twitch.game)
```

**En el chat:**
```
💬 Espectador: !infojuego
🤖 DomDimaBot: DomDima está jugando ahora mismo a Valorant
```

</TabItem>
<TabItem label="Argumentos">

Usa `&p1`, `&p2` y `&t` para usar lo que el espectador escribe después del comando.

```
!cc abrazo $(user) le manda un cálido abrazo a &p1! 🤗
```

**En el chat:**
```
💬 Espectador: !abrazo @AmigoUsuario
🤖 DomDimaBot: Espectador le manda un cálido abrazo a @AmigoUsuario! 🤗
```

```
!cc decir $(user) dice: &t
```

**En el chat:**
```
💬 Espectador: !decir este bot está increíble
🤖 DomDimaBot: Espectador dice: este bot está increíble
```

</TabItem>
<TabItem label="Contadores">

Las variables las creas tú. No existen hasta que les das un valor.

```
!cc victorias *(^(#victorias) ? %(#victorias *(%(#victorias) + 1)) : %(#victorias 1)) $(user) lleva victorias: %(#victorias)
```

**En el chat:**
```
💬 Espectador: !victorias
🤖 DomDimaBot: Espectador lleva victorias: 1
```

Cada uso siguiente suma una.

</TabItem>
<TabItem label="Triggers y otros comandos">

Una respuesta puede reproducir un trigger o ejecutar otro comando.

```
!cc airhorn $(trigger.send airhorn) ¡AIRHORN!
```

Si existe un trigger llamado `airhorn`, se reproduce cuando se ejecuta el comando.

```
!cc creador Mira mis enlaces aquí: #(discord)
```

Esto ejecuta el comando `discord` dentro de `creador`.

</TabItem>
</Tabs>

<Aside type="tip">
La página **Comandos** del dashboard muestra todos los comandos, su estado y su nivel de acceso en un solo lugar.
</Aside>
