## Task and route

This is a bounded but cross-cutting Rust interpreter task: preserve TypeScript AST evaluator ordering, context identity, storage behavior, and JavaScript coercion in an opt-in library with no production callers. The user's current model tier remains the starting baseline: GPT-6 Luna → MiniMax M3.1 Flash → DeepSeek V4.1 Flash → Grok 4.7 → GPT-6.1 Sol → GPT-6 Astra.

The same supported corpus is exercised across profiles, rather than counted as new distinct cases. Four worker dependency graphs match.

Source review found two actual compatibility defects. A DB-user memo key containing a lone surrogate was rejected by `to_utf8`; the final map uses generic `OrderedMap<T, K = String>` / `SharedMap<T, K = String>`, with only `user_command_variables` keyed by `JsString`, while native identity strings retain checked UTF-8 conversion. Queued command-reference `eventData` did not previously match JavaScript object spread; it now spreads enumerable object entries, array indices, and UTF-16 string units with shallow values, then overlays chatter fields. The exact two-case red probe failed before those fixes; both final regressions are green. `Engine::with_syntax` now selects an explicit Improved/custom syntax engine; default and `new` retain TypeScript-compatible syntax and source guards. The local-task `Rc<RefCell>` / `!Send` integration limit remains: HTTP or multithreaded embedding needs a local evaluator context/executor, and no runtime bridge is provided.

The initial runtime probe passed the then-current 3,518 supported source cases. Six core Clippy/style fixes and six example/test Clippy/style fixes followed; those were style corrections, not runtime-policy defects. The final 3,554 supported cases include the 36 review regressions added later.
