Text to speech (TTS) reads chat messages aloud in your stream. It generates audio and plays it through a browser overlay connected to your channel.

## Set up the speech overlay

1. Open your channel dashboard and go to **Modules → Text to Speech**.
2. Copy the channel's speech URL with **Copy speech URL**.
3. Add that URL as a browser source in your streaming software and keep it open while you want queued speech to play.
4. Enable or add a `!s` chat command for your channel, then use `!s Hello chat!` to check playback.

The overlay needs to be connected for queued messages to play. The queue accepts a limited number of pending messages; its maximum is configurable by the channel owner.

## Providers and voices

Choose the default provider in **Modules → Text to Speech**. The setting applies to `!s` and to default AST TTS functions.

### Piper

Piper is the local voice provider. Its available dashboard voices are:

- English (US): Ryan — `en_US-ryan-medium`
- Spanish (Mexico): Ald — `es_MX-ald-medium`

Piper synthesis does not consume AI credits. Expressive tags are removed before Piper speaks; the remaining words are still read.

### Fish Audio

Fish Audio provides cloned voices. The dashboard includes a voice browser, and its preset voices include Gojo, Rias Gremory, Carlos Bodoque, and Toji Fushiguro. The selected clone can be the channel's default voice or an explicitly named voice in an AST command.

Fish Audio usage consumes AI credits.

Both providers are available on Free, Premium, and Pro plans. AI credit limits are shared across eligible AI features and vary by plan; TTS does not have a separate monthly allowance.

## Chat command

### `!s` — speak a message

**Usage:** `!s <message>`

When enabled as a chat command, `!s` reads the message using the channel's configured default provider and voice. The channel's default language is used for the spoken username prefix (`say` or `dice`); choose English or Spanish in the TTS settings. The `!s` command is disabled in the shipped default command configuration, so enable or create it for your channel before using it.

```text
!s Hello chat, welcome to the stream!
```

The chat command applies the channel's message filters: skip emotes, replace links, normalize whitespace, and limit message length. The owner can change these in the TTS module. The message must still contain speakable text after filtering.

## AST functions

Use these functions in custom commands and AST actions:

| Function | Behavior |
|---|---|
| `$(tts <message>)` | Speaks with the channel's configured default provider and voice. |
| `$(tts.speak <message>)` | Alias for `$(tts ...)`; it does not force Piper. |
| `$(tts.ai <message>)` | Alias for `$(tts ...)`. |
| `$(tts.clone <voice_name> <message>)` | Speaks with the named Fish Audio voice. The first argument is a voice name or voice ID; the remaining text is spoken. |
| `$(tts.fish <voice_name> <message>)` | Alias for `$(tts.clone ...)`. |

```text
$(tts Hello chat!)
$(tts.speak This uses the channel default.)
$(tts.clone gojo Hello from Gojo!)
```

The queue processes one speech item at a time for a channel. If the browser overlay is disconnected, the server rejects new speech requests rather than adding them to the queue. The configured queue maximum also limits pending items.

## Expressive tags

Fish Audio supports expressive tags written in square brackets. Put tags in the message to request an emotion, delivery style, vocal sound, or effect:

```text
!s [happy] Great stream today!
!s [whisper] [pause] Can you keep a secret?
$(tts.clone gojo [excited] Let's go!)
```

The channel owner can enable or disable individual tags in **Modules → Text to Speech → Expressive voice controls**. Disabled and unrecognized tags are stripped before synthesis. Tags only affect Fish Audio; Piper strips them and speaks the remaining message.

## Configure TTS

In **Modules → Text to Speech**, the channel owner can configure:

- Whether TTS is enabled for the channel.
- The default language and provider.
- The English and Spanish Piper voices, or the Fish Audio default clone voice when Fish is selected.
- Maximum message length (30–500 characters).
- Maximum pending queue size (1–20 items).
- Whether chat-command messages skip emotes, replace links, and normalize whitespace.
- Which expressive Fish Audio tags are enabled.

Channel owners can change settings. Users with settings-view access can view them read-only. Voice previews and changes to settings are owner-only.

## AI credit use

Piper is free and consumes no AI credits. Fish Audio uses **1.5 AI credits per character**, rounded up for each synthesis. Credit limits are shared across AI features; the plan values currently configured by the product are:

| Plan | Monthly AI credits |
|---|---:|
| Free | 25,000 |
| Premium | 200,000 |
| Pro | 800,000 |
