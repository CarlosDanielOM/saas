After a stream ends, DomDimaBot can write a short recap of it and save what it learned as memories. **Modules → Stream Summaries** lists your past streams with their numbers, the recap, and the memory changes made from each one. It is available on every plan.

Viewing the list needs the `summaries:view` permission. Approving or changing the memories it proposes needs `memories:manage`.

## Turn on summaries

<Steps>

1. Open **Modules → AI Personality**.
2. Under **On or off**, turn on **Stream summaries**.
3. Under **Automatic upkeep**, turn on **Learn after each stream**. Both switches must be on.
4. Keep **Learn from chat** on if you want the bot to save memories from each recap. Without it, the recap is still written, but no memories are saved.
5. Select **Save changes**.
6. After your next stream ends, open **Modules → Stream Summaries**. The first recap usually appears a few minutes after the stream ends.

</Steps>

The **AI chat on** switch controls chat replies only. It does not turn summaries on or off.

## When a recap is written

A recap is written only for a stream that is long and busy enough. By default, a stream needs at least **20 minutes** and **30 chat messages**. A stream that misses either minimum shows **Too short** and gets no recap and no memory changes.

You can change both minimums under **Fine-tune the numbers** on [AI Personality](/ai-personality/).

Weekly and monthly cleanup runs also appear in the list when those switches are on, labeled as **Weekly memory cleanup** or **Monthly memory cleanup**.

## Read a stream

Select a stream in the list. The details show:

- **Length**, **Avg viewers**, and **Peak**.
- **Follows**, **Subs**, **Bits**, and **Tips**.
- **What happened**: the headline, recap, and highlights.
- **What the bot learned**: each memory change, with the **Why** and the chat evidence (**From chat**) behind it.

Each memory change shows a result:

| Result | Meaning |
|---|---|
| **Saved** | The memory was created, updated, archived, or removed. |
| **Couldn't save** | The change failed. |
| **Not saved: learning is off** | **Learn from chat** is off. |
| **Not saved: the bot was not sure enough** | Confidence was below the threshold for that action. |
| **Not saved: auto-save is off for this** | The matching automatic switch is off. |
| **Not saved: limit per stream reached** | The stream hit the maximum number of changes. |
| **Kept: still in use** | A deletion was skipped because the memory was used or updated too recently. |

## Stream status

| Label | Meaning |
|---|---|
| **Still writing…** | The recap is not finished. Check back in a few minutes. |
| **N memories saved** | At least one memory change was saved. Not every proposal has to be saved. |
| **Nothing new to remember** | The bot finished and found nothing worth saving. |
| **Too short** | The stream missed the minimum length or chat count. |
| **No changes needed** | A cleanup run found nothing to change. |
| **Couldn't finish** | Processing failed. The next stream is summarized as usual. |

## Limits

- The recap and memory suggestions come from an AI model, based on sampled chat and the stream's data. They can miss events, misread context, or contain errors. Use them to help you review, not as a full transcript.
- Processing can be delayed, or fail, when the data or the AI provider is unavailable.
- If your Twitch account is active and has an email address on file, the bot emails the recap after a successful stream summary.
- Generating summaries counts toward your channel's AI usage. See [Plans](/plans/) for allowances.

For plan allowances, see [Plans](/plans/). For memory review and the learning controls, see [Memories](/memories/) and [AI Personality](/ai-personality/).
