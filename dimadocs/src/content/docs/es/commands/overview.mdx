Los comandos son la base de DomDimaBot. Se dividen en dos categorías: **Comandos Predeterminados** (incluidos) y **Comandos Personalizados** (creados por ti).

## Comandos incluidos

El catálogo de comandos, su activación inicial, sintaxis y comportamiento están en la [referencia de comandos incluidos](/es/commands/built-in/). La configuración inicial activa las entradas salvo `!s` y `!clearchat`; cada canal puede tener otros ajustes. Usa `!commands` para ver los comandos disponibles para ti en un canal.

Esta página se centra en los comandos y temporizadores de chat recurrentes que crean los streamers. Para variables, funciones, condiciones y referencias a otros comandos, consulta las [guías de AST](/es/commands/advanced/).

## Comandos Personalizados

Los comandos personalizados los creas tú y pueden enviar texto, usar funciones AST, guardar datos, activar media y llamar otros comandos.

<Aside type="tip">
Consulta la página del [Dashboard](/es/dashboard) para una guía visual sobre cómo crear y gestionar comandos personalizados a través de la interfaz web.
</Aside>

### Cómo Crear Comandos Personalizados

Puedes crear comandos personalizados de dos maneras:

<Tabs>
<TabItem label="Por Chat">

Usa el comando `!cc` directamente en el chat:

```
!cc <nombre_comando> <respuesta>
```

El nombre del comando se crea **sin** el `!`.

**Ejemplo:**
```
😎Streamer: !cc discord ¡Mira mi Discord! discord.gg/ejemplo
🤖 DomDimaBot: ¡Comando !discord creado!
```

Con opciones:
```
!cc -cd=300 -ul=tier1 discord ¡Discord solo para subs! discord.gg/subonly
🤖 DomDimaBot: ¡Comando !discord creado con configuración personalizada!
```

| Opción | Descripción |
|--------|-------------|
| `-cd=` | Enfriamiento en segundos. El mínimo depende del plan del dueño del canal: Free `5`, Premium `3`, Pro `1`. |
| `-ul=` | Nivel de usuario: `everyone`, `tier1`, `tier2`, `tier3`, `vip`, `founder`, `mod`, `editor`, `admin`, `broadcaster` |

**Editar:** `!ec <nombre> <nueva respuesta>`  
**Eliminar:** `!dc <nombre>`

</TabItem>
<TabItem label="Por Dashboard">

Navega a la sección **Comandos** en tu dashboard para un editor visual con:

- Lista completa de comandos con interruptores de activar/desactivar
- Configuración de enfriamiento y permisos
- Editor de respuestas para texto / plantillas AST
- Gestión de temporizadores

</TabItem>
</Tabs>

### Comandos Básicos vs Avanzados

Hay dos formas útiles de entender los comandos personalizados:

| Tipo | Mejor para | Ejemplo |
|------|------------|---------|
| **Comandos de texto básicos** | enlaces, reglas, información simple | `!discord`, `!reglas`, `!horario` |
| **Comandos AST** | respuestas dinámicas, contadores, lógica, triggers | `!uptime`, `!abrazo`, sistemas de lealtad |

### Nota importante sobre AST

DomDimaBot **no** usa sintaxis tipo `{user}` o `{game}` para la lógica avanzada de comandos.

Usa:

- `$(user)` para el usuario actual
- `$(twitch.game)` para el juego actual
- `&p1`, `&p2`, `&t` para argumentos
- `%(...)` para variables que tú mismo creas

## Temporizadores de chat recurrentes

Los moderadores pueden gestionar mensajes de chat recurrentes con `!cct`, `!ect` y `!dct`, o mediante `!timer create|edit|delete|list`. Los temporizadores solo envían mensajes cuando el canal está en vivo. Los mensajes pueden usar la sintaxis AST.

```text
!cct redes 15 Visita los enlaces del canal!
!ect redes 30 Los enlaces actualizados están en los paneles.
!dct redes
!timer list
```

Los nombres de temporizador pueden contener letras, números y guiones bajos, con un máximo de `30` caracteres. Los mensajes pueden tener hasta `350` caracteres. Límites de temporizadores activos: Free `5`, Premium `15` y Pro `50`.

- Free: `15`, `30`, `45` o `60` minutos
- Premium: múltiplos de `5` entre `5` y `180` minutos
- Pro: cualquier número entero de minutos entre `1` y `180`

Introduce un número entero de minutos o usa el sufijo `m` o `h` (por ejemplo, `15m` o `1h`). Para editar un temporizador existente, el intervalo debe estar permitido por el plan actual. Si un cambio de plan deja un intervalo fuera del plan, el temporizador puede seguir funcionando, pero debes cambiarlo a un intervalo permitido antes de editarlo.

## Ejemplos de Patrones Correctos para Comandos Personalizados

<Tabs>
<TabItem label="Texto">

Respuestas de texto plano para información, enlaces y anuncios.

```
!cc discord ¡Mira mi Discord! discord.gg/ejemplo
```

**Ejemplo en chat:**
```
💬 Espectador: !discord
🤖 DomDimaBot: ¡Mira mi Discord! discord.gg/ejemplo
```

```
!cc reglas ¡Por favor sé amable y diviértete!
```

</TabItem>
<TabItem label="Funciones">

Las respuestas dinámicas deben usar funciones AST.

**Ejemplo:**
```
!cc gameinfo $(twitch.channel) está jugando ahora mismo a $(twitch.game)
```

**Ejemplo en chat:**
```
💬 Espectador: !gameinfo
🤖 DomDimaBot: DomDima está jugando ahora mismo a Valorant
```

</TabItem>
<TabItem label="Parámetros">

Usa `&p1`, `&p2` y `&t` cuando quieras recibir entrada del usuario.

**Argumento único:**
```
!cc abrazo $(user) le manda un cálido abrazo a &p1! 🤗
```

**Ejemplo en chat:**
```
💬 Espectador: !abrazo @AmigoUsuario
🤖 DomDimaBot: Espectador le manda un cálido abrazo a @AmigoUsuario! 🤗
```

**Texto restante:**
```
!cc decir $(user) dice: &t
```

**Ejemplo en chat:**
```
💬 Espectador: !decir este bot está increíble
🤖 DomDimaBot: Espectador dice: este bot está increíble
```

</TabItem>
<TabItem label="Datos Guardados">

Las variables AST las creas tú. No existen por defecto.

```
!cc wins *(^(#wins) ? %(#wins *(%(#wins) + 1)) : %(#wins 1)) $(user) ahora tiene %(#wins) wins!
```

**Ejemplo en chat:**
```
💬 Espectador: !wins
🤖 DomDimaBot: Espectador ahora tiene 1 wins!
```

En el siguiente uso:

```text
💬 Espectador: !wins
🤖 DomDimaBot: Espectador ahora tiene 2 wins!
```

</TabItem>
<TabItem label="Triggers y Encadenamiento">

Puedes disparar media configurada y llamar otros comandos desde AST.

**Ejemplo de trigger:**
```
!cc airhorn $(trigger.send airhorn) AIRHORN!
```

**Ejemplo en chat:**
```
💬 Espectador: !airhorn
🤖 DomDimaBot: AIRHORN!
```

Si existe un trigger llamado `airhorn`, se disparará cuando corra el comando.

**Ejemplo de referencia a comando:**

```
!cc creator Mira mis enlaces aquí: #(discord)
```

Esto ejecuta el comando `discord` dentro de `creator`.

</TabItem>
</Tabs>

### Comandos Personalizados Avanzados

Los ejemplos anteriores solo cubren lo básico. El sistema AST completo soporta:

- **Condiciones** con `*(...)`
- **Variables y almacenamiento** con `%(...)`
- **Verificación de existencia** con `^(...)`
- **Argumentos** con `&p1`, `&p2` y `&t`
- **Referencias a comandos** con `#(...)`
- **Bucles, arrays y lógica avanzada**
- **Llamadas a funciones** para Twitch, moderación, TTS, triggers, EventSub y más
