The **Clip overlay** plays a Twitch clip on your stream. Add its URL to OBS once. After that, the overlay plays a clip when a `!promo` runs or a `!so` finds a clip. Viewers can also create clips with `!clip`. See [Built-in commands](/commands/built-in/) for `!clip` and [Custom commands](/commands/overview/) for editing the default `!so` command.

**Who can set it up:** the channel owner, or an admin with clip management permission.

## Set up the overlay

1. Open your channel dashboard and choose **Modules → Clips**.
2. Pick a design card. **Classic** and **Third** are free. The other designs need Premium or Pro.
3. Set **Clip duration** from 1 to 30 seconds. The default is 30.
4. Select **Copy** next to **Browser Source URL**. In OBS, add a **Browser Source** with that URL. Use a width of 800. For a height, use 450 for Third, Cinema, Pill, HUD, and Slash, and 225 for the others.
5. Keep the overlay open. Opening the URL in a normal browser tab also connects it.
6. Select **Test this design**. The page opens an embedded overlay preview and plays an available clip from your channel. If the overlay isn't connected yet, the page asks you to open the Browser Source URL first. Testing requires a clip to be available on your channel.

The design and duration are part of the URL. If you change either one, copy the new URL into OBS. The page remembers your choices for each channel in this browser only, so set them again on another computer.

## Create clips in chat

- **`!clip`** creates a Twitch clip and posts its link. Everyone can use it by default, with a 10-second cooldown.
- **`!clip 20 Epic moment`** sets a length and a title. A length from 5 to 60 seconds is used; any other value falls back to 30 seconds.

Twitch only creates clips while the channel is live. You can change who can use `!clip` in your command settings.

## How clips reach the overlay

- **`!promo <user>`** (moderators and above by default) shows a clip of that streamer in the overlay when one is available.
- **`!so <user>`** (moderators and above by default) sends the shoutout and shows one of that streamer's clips when one is available. `!so` is an editable default custom command; its saved **Who can use it** setting controls access.

Clips are processed one at a time; a clip requested while another is playing waits in the queue. The overlay must be connected when a clip is requested: a request made while disconnected is skipped rather than saved for later. Download failures or playback timeouts can also prevent a clip from playing.

## Troubleshooting

- **The overlay isn't connected:** keep the overlay URL open in OBS or a browser tab. The test needs it to be open.
- **No clip plays:** confirm the overlay is open and that Twitch has a clip available for the channel. Twitch can take a while to create or return a clip.
- **The overlay looks like Classic:** the URL may be missing the design, or the design couldn't load. Copy the URL again from the page.
