Estas recetas son puntos de partida. Cada una es una respuesta completa de un comando personalizado, o un par de comandos cuando se indica. Prueba las recetas que cambian el estado del canal en un comando que solo tú puedas usar antes de abrirlo a otros. La sintaxis está en [Sintaxis y datos AST](/es/commands/advanced/syntax/), y todas las funciones están en la [Referencia de funciones AST](/es/commands/advanced/functions/).

## Contadores

### Contar cuántas veces pasó algo

```bash
*( ^(#wins) ? %(#wins *(%(#wins) + 1)) : %(#wins 1) )
$(user) tiene %(#wins) victorias!
```

La primera línea empieza el conteo en `1` si el valor todavía no existe, y después suma `1`. La segunda línea publica el total.

- Los valores del canal (`#`) vencen **24 horas después de su última escritura**. Si nadie ejecuta el comando durante un día, el conteo vuelve a empezar.
- Para un conteo que deba durar, usa una variable de base de datos: `%(*wins ...)` para un conteo por canal, o `%(**wins ...)` para uno por espectador. **Las escrituras en base de datos requieren Premium o Pro.** En el plan Gratis, la escritura se omite sin error. Consulta [Ejecución, errores y límites](/es/commands/advanced/execution/).

### Consultar el valor de otro espectador

```bash
%(##rank(&p1))
```

`&p1` es la primera palabra que escribió el espectador, así que el comando `!rank ronchi` lee el login `ronchi`. Si omites el selector, los valores `##` y `**` pertenecen a quien ejecuta el comando.

## Condiciones

### Elegir una de dos respuestas

```bash
*( %(#ready) == 1 ? "Listo" : "No listo" )
```

Un operador ternario `*( condición ? sí : no )` ejecuta una rama. Pon cualquier acción que cambie el canal solo en la rama donde debe ejecutarse.

### Ejecutar una acción solo si la condición es verdadera

```bash
*( %(#ready) == 1 ? "Listo" : "" )
```

Con una segunda rama vacía, no se publica nada cuando la condición es falsa.

## Acciones con tiempo

### Pausar un comando por un tiempo

Esto desactiva `!spoilers` durante cinco minutos y luego lo vuelve a activar:

```bash
$(disable.command spoilers 300)
!spoilers está pausado durante cinco minutos.
```

La duración está en segundos, de `1` a `604800`. El comando vuelve al estado que tenía antes del cambio, incluso si el bot se reinicia en medio. Consulta [Funciones de disponibilidad](/es/commands/advanced/functions/#funciones-de-disponibilidad).

### Enviar un mensaje y una acción más tarde

El timer devuelve el control de inmediato. Su mensaje y su acción se ejecutan después de cinco minutos, incluso si el bot se reinicia en medio:

```bash
$(timer 300 "¡Se acabaron los cinco minutos!" $(trigger.send airhorn))
```

Un timer se ejecuta como máximo una vez, y expira si llega con más de 10 minutos de retraso. Consulta [Ejecución, errores y límites](/es/commands/advanced/execution/).

## Resultados de predicciones

Usa dos comandos, para que un moderador elija al ganador después de ver las opciones. Los dos comandos deben tener acceso de **Moderadores**.

**Comando 1, `!predicciones`**: muestra la pregunta y las opciones numeradas.

```bash
$(get.prediction)
```

**Comando 2, `!ganador`**: resuelve la predicción. El moderador escribe el título de la opción o su número.

```bash
$(end.prediction &t)
```

Luego un moderador escribe `!ganador Sí` o `!ganador 1`. `&t` mantiene junto un título de varias palabras. `end.prediction` consulta en Twitch la predicción actual cada vez, y rechaza un número que no existe o un título que coincide con dos opciones.

<Aside type="caution">
No pongas `$(end.prediction 1)` en la misma respuesta que `$(get.prediction)`. Así el ganador se elige sin que nadie lea antes las opciones. Mantén los dos pasos en comandos separados.
</Aside>

## Dividir un comando grande en varios

Cuando un comando se vuelve difícil de leer, pasa partes a sus propios comandos y llámalos con `#(nombreComando argumentos...)`.

```bash
¡Bienvenido $(user)!
#(reglas)
```

Aquí `!bienvenida` publica su saludo, y después se ejecuta `!reglas` y publica su propia respuesta. Si el argumento tiene signos de puntuación como `;`, `?` o `/`, ponlo entre comillas, por ejemplo `#(encuesta "¿Mejor mapa?;Nuke/Mirage")`. Sin comillas, esos caracteres pueden cambiar en el camino.

Ten en cuenta estos límites:

- Se pueden anidar hasta **cinco** niveles de llamadas, y una sola ejecución puede hacer como máximo **50** llamadas.
- Un comando no puede llamarse a sí mismo, ni directamente ni a través de otro comando.
- El comando llamado **no verifica su propia configuración de acceso** cuando lo llama un comando que tú escribiste. Solo aplica el acceso del comando que hace la llamada. Por eso, llama a un comando solo para moderadores únicamente desde un comando que también esté limitado a moderadores.
- Cada comando llamado publica su propia respuesta, después de la respuesta principal.

Consulta [Ejecución, errores y límites](/es/commands/advanced/execution/) para más detalles.

## Resumen de patrones

| Patrón | Sintaxis | Para qué sirve |
|--------|----------|----------------|
| Contar o iniciar un conteo | `*(^(#x) ? %(#x *(%(#x) + 1)) : %(#x 1))` | Crear un contador que falta o sumarle `1` |
| Consulta de espectador | `%(##rank(&p1))` | Leer un valor guardado para un espectador |
| Valor persistente de espectador | `%(**rank(&p1))` | Leer un valor de base de datos del espectador (guardarlo requiere Premium o Pro) |
| Condición | `*(condición ? SÍ : NO)` | Elegir uno de dos resultados |
| Acción condicional | `*(condición ? ACCIÓN : "")` | Hacer algo solo si la condición es verdadera |
| Acción con tiempo | `$(timer segundos "mensaje" $(acción))` | Ejecutar después, como máximo una vez |
| Llamar a otro comando | `#(nombreComando argumentos...)` | Ejecutar un comando separado después de la respuesta |

<Aside type="tip">
¿Necesitas saber qué hace una función o qué plan requiere? Consulta la [Referencia de funciones AST](/es/commands/advanced/functions/). Para los límites, consulta [Ejecución, errores y límites](/es/commands/advanced/execution/).
</Aside>
