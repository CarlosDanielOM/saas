The dashboard is scoped to a channel. Open **Dashboard**, **Commands**, **Modules**, or **Settings** from the top navigation. On a narrow screen, open the menu to reach the same sections.

## Dashboard overview

The main page shows the channel's live or offline status and, when live, stream details such as viewer count, game, and title. It also shows activity counters, stream history, and AI usage information where available. Values depend on the data the channel has collected.

Use **Join Bot** or **Leave Chat** on this page to change whether DomDimaBot participates in chat. The page shows chat and connection status next to this control.

## Find a feature

| Navigation | What you can do |
|---|---|
| **Commands** | Create, edit, and manage channel chat commands. |
| **Modules** | Browse features such as triggers, TTS, moderation, and analytics. A module card shows its availability or plan requirement. |
| **Settings** | Manage the channel's dashboard administrators. Owners can add or remove admins. |
| **Profile menu** | Open profile settings, view your plan, buy credits, change theme or language, and sign out. |

Some module pages are experimental or still in development. Check the status shown on each card before relying on it for a live stream. The [modules guide](/modules/) lists current statuses.

If the header shows **Activate Bot**, **Reauthenticate**, or **Update Permissions**, follow it to grant or renew Twitch permissions. See [Getting Started](/getting-started/).
