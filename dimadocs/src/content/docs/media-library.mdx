The **Media Library** holds the sounds, videos, images, and GIFs that your [Triggers](/triggers/) and [DimaFX](/dimafx/) use. Open it from **Modules → Media Library**. Every item shows its name, type, visibility, and how much storage it uses. Select **Refresh** to reload the list. Uploading needs the **Upload media** permission: be the channel owner or an admin with that permission.

This library is for trigger and DimaFX media. Design images and videos for [Overlay Studio](/overlay-studio/) live in the separate **Asset Library** under **Settings** (see [Design assets](#design-assets)).

## Upload media

1. Select **Upload**.
2. Choose a file, or drag it into the box.
3. Enter a name. Use letters, numbers, and underscores. Spaces become underscores. The name must start with a letter and can be up to 60 characters.
4. Pick **Who can use it** (Premium and Pro only), then select **Upload**.

The server checks each file's MIME type against this list:

- **Video:** `video/mp4`, `video/mov`, `video/avi`, `video/flv`, `video/wmv`, `video/webm`, `video/mkv`
- **Image:** `image/gif`, `image/jpg`, `image/jpeg`, `image/png`, `image/bmp`, `image/tiff`, `image/svg`, `image/webp`
- **Audio:** `audio/mp3`, `audio/flac`, `audio/wav`, `audio/ogg`, `audio/aac`, `audio/wma`, `audio/m4a`

Browsers often label MP3 and MOV files with other MIME types (`audio/mpeg` and `video/quicktime`), and those are not on the list. If an upload says the file type is not allowed, convert it to a listed format, such as WAV or M4A for audio, or MP4 for video.

## Limits by plan

| Plan | Largest file | Private storage |
|---|---:|---:|
| Free | 5 MB | None. Uploads are public. |
| Premium | 25 MB | 250 MB |
| Pro | 100 MB | 1 GB |

Private files count toward your storage. Public files do not.

## Private and public media

- **Private** files belong to your channel. They use your private storage.
- **Public** files appear in the shared public library. Other streamers can use them, and they do not use your storage. Free uploads are always public.

To add a public file, select **Browse public library**, find the item, and add it. Adding a public file costs no storage.

**Make public** moves a private file to the public library and frees its storage. **This cannot be undone.** A public file cannot become private again, and only DomDimaBot support can remove it.

## Rename and delete

- **Rename** changes the name in your library only. Trigger and DimaFX names stay the same.
- **Delete** removes an item from your library. You cannot delete an item that a trigger or DimaFX item still uses. The page lists where each item is used. Remove it from those first.
- Removing a public file from your library does not delete the shared public file.
- When the last library copy of a private file is removed, its stored file is deleted.

## Design assets

Use **Settings → Asset Library → Browse Asset Library** to upload files for Overlay Studio designs. The Asset Library accepts:

- **Images and videos:** PNG, JPEG, GIF, WebP, MP4, and WebM.
- **Alert sounds:** MP3, WAV, and Ogg audio up to 10 minutes long.

Each file can be up to 50 MB. Design storage is 100 MB on Free, 500 MB on Premium, and 5 GB on Pro. These limits are separate from trigger media. Design assets cannot be used as triggers.

To delete a design asset, first remove it from any saved design, and republish any overlay that uses it. See [Overlay Studio](/overlay-studio/) for setup.
