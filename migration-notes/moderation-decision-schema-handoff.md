# Moderation decision schema handoff

The opt-in `moderation-decision-schema` feature maps the `ModerationDecision` model descriptor to the existing `SchemaDefinition` and `SchemaRepository`. It reuses the native channel moderation `IModerationRule`, shared BSON caster, and Mongo repository. The typed interface retains local number-valued `ModerationMatch` coordinates because TypeScript declares arbitrary `number` values while the existing native advanced matcher uses `usize`. Mixed fields remain BSON in the persistence API. The model descriptor records the source TTL and three compound indexes; construction is disconnected and index creation is explicit.

Verification is complete for this bounded model mapping. The pinned actual-source Mongoose oracle exercised 18 constructor cases, including the three application schema fixtures, decision model constructor, and shared flat-upsert SDK behavior. The final schema fixture is SHA-256 `893257129dde0b47dfda72a21df25ff1e06d7e207b08e453a41b53717c193800`. A fresh actual-source regression replay of the related variation schema covered 42 cases and retained the old expected output byte-for-byte. The isolated compiler-fixtures phase also exercised private Mongo CRUD and index behavior for the new model alongside the existing variation-job fixtures and strict feature profiles. Exact accepted phase IDs, source binding, retained attempt history, and production/resource readback are in [the evidence package](evidence/2026-10-30-moderation-decision-model/README.md).

This is a partial local schema mapping, not the full decision application path or general Mongoose replacement. The model descriptor and native repository do not reproduce arbitrary Mongoose document identity, save hooks, middleware, or all casting behavior. The TypeScript model callers, decision producer, moderation route/handler, semantic worker, and surrounding persistence/adoption path remain separate migration work. Caller adoption and deployment are reported separately from local feature evidence; neither is inferred here. No benchmark was run.
