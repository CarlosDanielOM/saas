Seven samples after 100 warmups. 10,000 operations per sample; 1,000 for the large record (1,000 tags and 200 languages). All four outputs, byte counts, and checksums match. Input parsing and I/O are excluded.

The first Rust version took 1.50× the Node time for boundary cuts, 1.41× for tags, and 2.81× for the large case. Those raw results are retained. The optimized code borrows unchanged tag strings and appends JSON into one buffer.

The boundary case is near parity; its small difference does not support a speedup claim. These sequential pinned-container runs share a host and do not measure provider latency, whole-service throughput, CPU, or RSS.
