What changed and how it was checked

Static string keys replace repeated allocations. Typed and plain AI events share one assembler, removing temporary JSON objects. Objects without numeric keys skip sorting allocations. The formatter uses the existing JSON crate for Node-compatible decimal ties and a bounded integer shortcut. All 192 expected payload wires and every trial checksum matched. The decimal oracle covers 35,464 binary64 inputs. The command event's trial ranges overlap; its modest median gain needs workload-specific confirmation. No CPU or RSS measurement is claimed.
