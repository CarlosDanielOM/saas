## Source contract and native mapping

The TypeScript model is `channel_fish_voice_favorites`, stored in the `channel_fish_voice_favorites` collection. Its channel record has a required `channelID`, a `favorites` array defaulting to empty, a unique channel index, and no generated subdocument IDs. Each public `FishVoiceFavorite` has `id`, `name`, and `alias`; the limit is 20. The actual Mongoose oracle confirmed the model/collection name, `__v` version key, disabled timestamps, index, paths and subdocument option.

The native schema descriptor preserves those declared fields and index, and its Mongo repository provides the source-shaped get, add, remove and rename operations. The nine runtime exports map to `schema`, the typed `Favorite` and `FavoriteAliasError` records, the limit constant, alias helpers, and concrete repository entry points. The private channel document shape is represented by the schema descriptor. Index installation and Mongo access are explicit on a caller-owned database.

Dependency closure is bounded to what the feature uses. Mongoose schema/model construction maps to the existing native schema core, MongoDB driver and BSON support. The source imports `FISH_VOICES`; the native feature uses the matching four catalog data rows, not the whole Fish provider. Rename's legacy `voices.cloneDefault` migration uses the existing native channel TTS settings schema and Mongo path. String, lossless JSON and Unicode support reuse existing utilities; alias creation uses the accepted Unicode 17 NFKD implementation. No Cargo dependency was added.

## Behavior boundaries

Alias validation follows the source's whitespace trim, Unicode lowercase, ASCII grammar and reserved-name rejection. Generation uses NFKD, removes U+0300–U+036F, lowercases, normalizes separators, caps the base, and adds collision suffixes. The native `JsString` preserves UTF-16 units through these helpers. Lone surrogates are replaced only at the BSON UTF-8 boundary, matching the pinned BSON behavior; newly returned values retain their original string as in the source.

The contract is ordinary typed BSON, not arbitrary JavaScript or Mongoose runtime parity. Malformed stored records are rejected and undeclared favorite fields are projected away. Unknown-shape objects, dynamic properties/prototypes, general model behavior, JavaScript `Error` subclass identity, and engine-specific stack formatting are not claimed. Rename is not transactional: the legacy settings update can persist before a later favorite update fails. The real Mongo run covered concurrent add/rename behavior, capacity, CRUD, timestamp effects, BSON replacement and malformed data; a forced 21-conflict exhaustion schedule is an emulator proof, not a claim about a real Mongo schedule.
