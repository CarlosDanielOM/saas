Text to speech (TTS) reads chat messages aloud in your stream. It generates audio and plays it through a browser overlay connected to your channel.

## Set up the speech overlay

1. Open your channel dashboard and go to **Modules → Text to Speech**.
2. Copy the channel's speech URL with **Copy speech URL**.
3. Add that URL as a browser source in your streaming software and keep it open while you want queued speech to play.
4. Enable or add a `!s` chat command for your channel, then use `!s Hello chat!` to check playback.

The overlay needs to be connected for queued messages to play. The queue accepts a limited number of pending messages; its maximum is configurable by the channel owner.

## Providers and voices

Choose the default provider in **Modules → Text to Speech**. The setting applies to `!s` and to default AST TTS functions.

### Piper

Piper is the local voice provider. Its available dashboard voices are:

- English (US): Ryan — `en_US-ryan-medium`
- Spanish (Mexico): Ald — `es_MX-ald-medium`

Piper synthesis does not consume AI credits. Expressive tags are removed before Piper speaks; the remaining words are still read.

### Fish Audio

Fish Audio provides cloned voices. The dashboard includes a voice browser, and its preset voices include Gojo, Rias Gremory, Carlos Bodoque, and Toji Fushiguro. The selected clone can be the channel's default voice or an explicitly named voice in an AST command.

Fish Audio usage consumes AI credits. In the voice browser, channel owners can save up to 20 voices as favorites and rename each favorite's nickname. The UI continues to show the voice's display name (for example, **Pinky Pie** or **Carlos Bodoque**) and shows its nickname alongside it. A nickname is 1–40 letters, numbers, or underscores, starts with a letter, and is normalized to lowercase. Spaces in a voice's display name become underscores in its generated nickname: **Pinky Pie** normally gets `pinky_pie`; a number suffix is added if that nickname is already in use.

For `$(tts.clone ...)` and its alias `$(tts.fish ...)`, the first argument is a single voice key: use a built-in key such as `carlos_bodoque`, a saved favorite's nickname such as `pinky_pie`, or a Fish voice ID. The display name with spaces is not parsed as one voice argument. For example, to speak using the built-in Carlos Bodoque voice in a command that passes the triggering text, use `$(tts.fish carlos_bodoque &t)`. If a voice is saved as a favorite and its nickname is changed to `bodoquin`, use `$(tts.fish bodoquin &t)`. `$(set.voice ...)` accepts a favorite's nickname or its full display name, including spaces.

Both providers are available on Free, Premium, and Pro plans. AI credit limits are shared across eligible AI features and vary by plan; TTS does not have a separate monthly allowance.

## Chat command

### `!s` — speak a message

**Usage:** `!s <message>`

`!s` runs as a regular AST command and reads the message using the channel's configured default provider and voice. Its default template speaks the username followed by `dice:` and the message. Edit the Speech Chat command to change that template; the TTS language setting selects the voice language and does not change the template text. The shipped **Speech Chat** command `!s` is enabled by default for everyone. You can edit it from this page or from **Commands**. Its default cooldown is 0 seconds; only one editable command per channel can use a 0-second cooldown. Other commands must use a cooldown of at least 5 seconds on Free, 3 seconds on Premium, or 1 second on Pro.

```text
!s Hello chat, welcome to the stream!
```

The chat command applies the channel's message filters: skip emotes, replace links, normalize whitespace, and limit message length. The owner can change these in the TTS module. The message must still contain speakable text after filtering.

## AST functions

Use these functions in custom commands and AST actions:

| Function | Behavior |
|---|---|
| `$(tts <message>)` | Speaks with the channel's configured default provider and voice. |
| `$(tts.speak <message>)` | Speaks with Piper, even when Fish Audio is the channel default. |
| `$(tts.ai <message>)` | Alias for `$(tts ...)`. |
| `$(tts.clone <voice> <message>)` | Speaks with a Fish Audio voice. Use a built-in voice name, a saved favorite's nickname, or a Fish voice ID as the first argument; the remaining text is spoken. |
| `$(tts.fish <voice> <message>)` | Alias for `$(tts.clone ...)`. |
| `$(set.voice <voice>)` | Changes the channel's default Fish Audio voice and selects Fish Audio as the provider. Use one of the four built-in voice names, or a saved favorite's nickname or display name. This action requires moderator-level access. |

```text
$(tts Hello chat!)
$(tts.speak This uses Piper.)
$(tts.clone gojo Hello from Gojo!)
$(tts.fish carlos_bodoque &t)
$(tts.fish pinky_pie &t)
$(tts.fish bodoquin &t)
$(set.voice my_favorite)
```

Save a voice as a favorite before changing its nickname. Built-in voices can also be used directly by their built-in keys, such as `carlos_bodoque`; renaming a saved favorite changes the nickname used in AST, not the name shown as the voice's display name.

The queue plays speech in order, one item at a time per channel. Its configured maximum (1–20) counts the item currently playing along with queued items. If the browser overlay is disconnected, the server rejects new speech requests. When it reconnects, speech still waiting in the queue can continue; speech interrupted by the disconnect is not replayed.

## Expressive tags

Fish Audio supports expressive tags written in square brackets. Put tags in the message to request an emotion, delivery style, vocal sound, or effect:

```text
!s [happy] Great stream today!
!s [whisper] [pause] Can you keep a secret?
$(tts.clone gojo [excited] Let's go!)
```

The channel owner can enable or disable individual tags in **Modules → Text to Speech → Expressive voice controls**. Disabled and unrecognized tags are stripped before synthesis. Tags only affect Fish Audio; Piper strips them and speaks the remaining message.

The available tags are grouped as follows.

### Emotions

`[happy]` `[sad]` `[angry]` `[excited]` `[calm]` `[nervous]` `[confident]` `[surprised]` `[scared]` `[worried]` `[disappointed]` `[curious]` `[sarcastic]` `[satisfied]` `[delighted]` `[upset]` `[frustrated]` `[depressed]` `[empathetic]` `[embarrassed]` `[disgusted]` `[moved]` `[proud]` `[relaxed]` `[grateful]` `[disdainful]` `[unhappy]` `[anxious]` `[hysterical]` `[indifferent]` `[uncertain]` `[doubtful]` `[confused]` `[regretful]` `[guilty]` `[ashamed]` `[jealous]` `[envious]` `[hopeful]` `[optimistic]` `[pessimistic]` `[nostalgic]` `[lonely]` `[bored]` `[contemptuous]` `[sympathetic]` `[compassionate]` `[determined]` `[resigned]`

### Voice and delivery

`[whisper]` `[shouting]` `[soft]` `[singing]` `[slow]` `[fast]` `[emphasis]` `[screaming]`

### Vocal sounds

`[laugh]` `[chuckle]` `[giggle]` `[cry]` `[sigh]` `[gasp]` `[inhale]` `[exhale]` `[sobbing]` `[groaning]` `[panting]` `[yawning]` `[snoring]` `[clear throat]`

Common aliases include `[anger]` for `[angry]`, `[whispering]` for `[whisper]`, `[laughing]` for `[laugh]`, and `[crowd laughing]` for `[audience laughing]`.

## Configure TTS

In **Modules → Text to Speech**, the channel owner can configure:

- Whether TTS is enabled for the channel.
- The default language and provider.
- The English and Spanish Piper voices, or the Fish Audio default clone voice when Fish is selected.
- Maximum message length (30–500 characters).
- Maximum number of queued and currently playing items (1–20).
- Whether chat-command messages skip emotes, replace links, and normalize whitespace.
- Which expressive Fish Audio tags are enabled.

Channel owners can change settings. Users with settings-view access can view them read-only. Voice previews and changes to settings are owner-only.

## AI credit use

Piper is free and consumes no AI credits. Fish Audio uses **1.5 AI credits per character**, rounded up for each synthesis. Credit limits are shared across AI features; the plan values currently configured by the product are:

| Plan | Monthly AI credits |
|---|---:|
| Free | 25,000 |
| Premium | 200,000 |
| Pro | 800,000 |
