DomDimaBot commands are split into two main areas:

- **Commands Overview** — built-in commands, permissions, and the default command set
- **Advanced Custom Commands (AST)** — syntax, functions, execution rules, and recipes for complex commands

Start with [Commands Overview](/commands/overview/) if you want the basics, or jump into [Advanced Custom Commands (AST)](/commands/advanced/) if you want programmable command logic.
