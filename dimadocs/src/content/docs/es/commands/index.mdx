Los comandos de DomDimaBot se dividen en dos áreas principales:

- **Comandos Overview** — comandos integrados, permisos y el set de comandos por defecto
- **Comandos Personalizados Avanzados (AST)** — sintaxis, funciones, reglas de ejecución y recetas para comandos complejos

Empieza con [Commands Overview](/es/commands/overview/) si quieres lo básico, o salta a [Comandos Personalizados Avanzados (AST)](/es/commands/advanced/) si quieres lógica programable para comandos.
