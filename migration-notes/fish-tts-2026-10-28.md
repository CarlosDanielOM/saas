# Fish TTS native service slice — 2026-10-28

## Status and scope

This wave adds a native Rust implementation of the Fish TTS HTTP service slice and its shared request/result and speech-path contracts. The implementation is in [`fish_tts.rs`](../dimabot/src/server/services/tts/fish_tts.rs), [`fish_protocol.rs`](../dimabot/src/server/services/tts/fish_protocol.rs), [`speech_paths.rs`](../dimabot/src/server/services/tts/speech_paths.rs), [`tts_provider.rs`](../dimabot/src/server/services/tts/tts_provider.rs), and the TTS module registration. OpenRouter attribution constants are in [`app_attribution.util.rs`](../dimabot/src/utils/ai/openrouter/app_attribution.util.rs). The source behavior references are the existing [`fish_tts.service.ts`](../dimabot/src/server/services/tts/fish_tts.service.ts), the installed `fish-audio` 0.1.0 HTTP subset, and the TypeScript backend tests; these sources remain active.

The slice implements the primary OpenRouter Fish model (`fish-audio/drama-3`) and fallback Fish Audio `s2.1-pro` HTTP requests, narrow MessagePack encoding compatible with `@msgpack/msgpack` 3.1.3, Fish cue reinforcement, error parsing/formatting, pooled immutable HTTP client use, output writing, public path generation, per-attempt deadlines, bounded retry behavior, and cancellation through retry backoff. The direct SDK's unrelated WebSocket API is outside this HTTP subset. Speech root and public API URL are explicit runtime configuration inputs; the application wiring that supplies them is not implemented. This service is not registered as an application provider and no TypeScript caller has cut over.

The implementation preserves source UTF-16 text and reference code units, including lone surrogates in provider request encoding and remote error text handling. Rust `String` path inputs still require valid UTF-8; an unpaired surrogate in a JavaScript path ID would fail at the Rust string boundary and is not covered by this API. File path behavior is intended to match the existing Node helper for ordinary valid Unicode inputs, not to establish a path security boundary.

## Compatibility decisions and boundaries

- The native path caps remote error bodies at 1 MiB and error JSON nesting at 128. This is an explicit resource bound; arbitrarily large/deep provider error payloads are not parity targets.
- Error redaction applies to remote response bodies. A failed early attempt demonstrated that broad textual redaction corrupted the static `fish-audio` model identifier when it contained the key string. The final implementation targets only the remote body and has a regression for the static model text. The failed compiler run `compiler-1793222439398514104` is preserved as history, not final evidence.
- Transport, JSON parser, operating-system, and active-abort diagnostics are normalized rather than byte-for-byte identical to Node. The native HTTP client blocks a rare scheme-only same-host/port redirect that Node may follow; an injected client owns its redirect policy. Empty successful audio is rejected.
- Provider `Retry-After`, reset headers, exponential backoff, and jitter are retained because they protect external provider rate limits and failure recovery. Backoff is interruptible by caller cancellation; this is request retry policy, not worker pacing.
- This source snapshot adds no crate/version, lockfile change, default feature, or worker-profile change.

The broader TTS call graph remains open: Piper and Kokoro providers, the emote catalog, queues, application service/provider registration, and runtime construction of `SpeechPaths` remain outstanding. A service trait/request type or isolated HTTP implementation does not complete those adapters. No TypeScript source was archived in this wave; the 14 previously archived leaf helpers are unchanged. Local Fish HTTP behavior is therefore one verified native slice, not a dependency-complete TTS migration or a total migration percentage.

There was no caller adoption, deployment, push, or production service change. The compiler receipt's production identity check remained unchanged.
