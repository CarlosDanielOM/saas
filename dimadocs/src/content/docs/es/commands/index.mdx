## Dónde administrar los comandos

- **En el chat:** `!commands` muestra los comandos que puedes usar en este canal. Los moderadores pueden crear, editar y eliminar comandos personalizados con `!cc`, `!ec` y `!dc`.
- **En el dashboard:** abre **Comandos** para activar o desactivar comandos, cambiar quién puede usarlos, definir los tiempos de espera y editar respuestas.
- **Para espectadores:** la **Lista para espectadores** de la página Comandos muestra los comandos que cada espectador puede usar. Usa **Copiar enlace** para compartirla.
