This closes only the `links.rule.ts` source row; the surrounding registry, handler, settings persistence and enforcement remain TypeScript.

The source regex is deliberately permissive, not a URL validator. The port reuses `JsString`, `js_compat` and the verified Unicode 17 lowercase core. No additional runtime or service adapter is needed for this typed evaluator.
