The **Redemptions** dashboard manages custom Channel Points rewards created through DomDimaBot and displays your Twitch rewards. A reward is a Twitch point redemption; DomDimaBot can process its redemption and run the message configured for that reward.

## Create a DomDimaBot reward

1. Open **Redemptions** in your streamer dashboard and choose **Create reward**.
2. Set a title and point cost. You can also set a prompt, a global cooldown in seconds, a message, duration, background color, whether viewer input is required, and whether Twitch should skip its redemption request queue.
3. Save the reward. DomDimaBot creates the custom reward in Twitch and registers to receive its redemption events.

You can edit, enable or disable, and delete custom rewards from the dashboard. The **Twitch** section lists rewards fetched from Twitch; use its refresh button to reload that list.

## Configure what happens on redemption

The **Message** field is processed by DomDimaBot's special-command parser when the reward is redeemed. For example, a message containing `$(trigger.send airhorn)` can play a configured trigger. The parser receives the viewer name, login, reward title, and any viewer input as context for supported commands. A trigger action also requires its OBS browser source to be connected; see [Triggers & Media](/triggers/).

The dashboard does not create separate built-in reward types for TTS, sounds, shoutouts, or other actions. Configure the reward message with supported bot commands for the action you want. If chat is enabled, a nonempty parsed message is also sent to chat.

## Cooldowns and reward settings

The cooldown field maps to Twitch's **global cooldown** for that reward. It is not a shared cooldown across all rewards or a per-viewer cooldown. Cost, prompt, enable state, viewer-input requirement, and request-queue behavior are reward settings sent to Twitch. DomDimaBot's reward message is local processing data used when the redemption event arrives.

DomDimaBot also shows the reward's duration and background color. Paid plans can edit the optional original-cost and cost-change settings; these can raise the reward's cost after a redemption. The return-to-original-cost option controls whether the changing cost is restored.
